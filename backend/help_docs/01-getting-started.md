# 快速开始

帮助中心用于说明滨湖智慧平台各项功能的用途、操作步骤和常见边界。不同岗位看到的菜单不同；如果本文提到的入口没有出现在你的侧边栏，通常表示当前账号没有对应权限，而不是页面故障。

## 第一次登录建议完成的事项

1. 点击侧边栏底部的姓名，进入个人资料，确认姓名、岗位和所属社区是否正确。
2. 进入“设置 → 账号与安全”，修改临时密码并妥善保管。
3. 进入“设置 → 个性化设置”，选择浅色、深色或跟随系统，并设置手机端使用侧边栏还是底部 Dock。
4. 回到仪表盘，查看自己的待办、公告和任务入口。

## 日常工作顺序

1. 从仪表盘或“流口指令核查”进入待处理任务。
2. 先核对姓名、身份证号、手机号和原始地址，再填写核查结果。
3. 文本停止输入约 700 毫秒后自动保存；下拉、日期等选择后立即保存。
4. 看到“已保存”再离开页面；如果显示“保存失败”，保留当前草稿并点击重试。
5. 需要基础管控处理的任务会进入研判、调照片或其他协作流程。

## 页面状态怎么看

- **保存中**：正在把本次修改写入本地任务池。
- **已保存**：本次修改已经成功保存。
- **保存失败**：数据未写入，但页面会保留你的输入，可重试。
- **数据冲突**：其他人员刚刚修改过同一任务，需要刷新后重新核对。
- **来源异常**：本地任务存在重复或冲突来源，普通用户只能查看，需管理员先处理来源。

## 使用时要注意

- 平台已完全使用本地业务数据，不再读写腾讯表格。
- 不要在备注中复制与工作无关的敏感信息。
- 不要用刷新页面代替保存状态确认。
- 发现人员、社区或权限错误时，先联系管理员修正基础资料，不要通过填写错误社区绕过限制。

## 从哪里继续了解

在帮助中心左侧选择对应功能，也可以用搜索框查找“待登记”“无法核实”“批量分配”“导出”等关键词。
