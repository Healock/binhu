# 账号、通知与界面设置

## 个人资料

点击侧边栏底部的姓名进入个人资料。这里可以查看账号显示姓名、岗位、部门、社区和个人贡献记录。姓名、岗位或部门有误时，请联系超级管理员在人员管理或用户管理中修正。

## 修改密码

进入“设置 → 账号与安全”：

1. 输入当前密码。
2. 输入并确认新密码。
3. 保存后重新登录验证。

临时密码会持续显示提醒。不要把密码写进备注、帮助文档或聊天截图。

## 头像

在个人资料或账号设置中上传头像。网页端和桌面客户端都会从平台读取同一头像；上传后如未立即刷新，可重新进入页面查看。图片应清晰、尺寸适中，不要上传包含身份证或业务材料的截图。

## 公告与通知

侧边栏底部的通知入口会显示系统公告和个人任务提醒：

- 重要公告可能在登录后弹出，阅读后可标记已读。
- 个人通知通常与任务、后台处理或系统异常有关。
- 删除公告不会删除业务数据，但只有具备公告管理权限的人员可以发布或撤下公告。

## 主题与导航

进入“设置 → 个性化设置”：

- 主题可选浅色、深色或跟随系统。
- 手机端可使用侧边栏或底部 Dock。
- Dock 可按岗位和权限调整常用入口；没有权限的页面不会因为加入 Dock 而获得访问权。

## 快捷功能

点击右下角的快捷功能按钮展开入口，再次点击收起。“我的任务记录”可查看本人操作过的任务；拥有任务队列权限的管理人员还可打开“管理任务队列”。打开抽屉后可刷新或关闭，菜单不会扩大账号权限。

电脑可按住主悬浮球拖动，手机可用手指拖动。松手后菜单停在新位置，拖动不会打开或关闭菜单；展开入口随主球移动，靠近屏幕边缘时会向屏幕内展开。窗口大小改变时会调整位置，避免按钮超出可见区域。按钮不显示悬浮提示。

## 会话与登录安全

- 平台会在长时间无操作后提醒并退出。
- 账号在其他设备登录或会话失效时，页面会要求重新登录。
- 桌面客户端升级不会清除正常的本地配置和登录状态；若升级后被要求重新登录，按页面提示操作即可。
