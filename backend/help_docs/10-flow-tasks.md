# 流口指令核查

“流口指令核查”是网格员、组长和相关管理岗位处理指令任务的主要入口。

## 查找任务

列表默认显示全部状态，可按以下条件组合筛选：

- 业务类型；
- 普通待处理、等待研判、已研判、来源异常、已完成；
- 社区、小区和地址匹配状态；
- 核查人、关键词和其他页面提供的业务条件。

筛选和排序会直接影响页面结果。使用“导出当前结果”时，导出文件应与当前筛选、排序一致，页面第一条也应是文件中的第一条业务数据。

## 领取和编辑

1. 打开任务详情，先核对核心人员信息和原始地址。
2. 未分配任务在第一次填写时会提示领取；确认后领取和修改会一次提交。
3. 文本、地址和备注停止输入约 700 毫秒后自动保存。
4. 核查结果、日期、核查人等选择后立即保存。
5. 保存失败时不要反复刷新，先使用页面的重试入口。

## 核查结果

不同业务允许的结果略有区别。常见结果包括已登记、待登记、离苏、无需登记、无法核实和移交。以下规则尤其重要：

- 普通用户不能直接选择“已登记”；需要登记时选择“待登记”并关联唯一拟登记房屋。
- 选择“无法核实”后，任务进入两级研判流程，不能把自由备注当成研判完成。
- “移交（所内）”由基础管控及更高岗位选择目标社区和接手组长。
- 结果变更后应等待页面显示“已保存”。

## 来源异常

来源异常表示同一任务存在重复、冲突或无法安全定位的本地来源。此类任务保持只读，页面会显示异常原因。管理员修复来源后，任务会恢复到原有业务阶段。

## 小屏幕使用

紧凑窗口会把姓名、身份证号、手机号和原地址合并为多行人员信息，核心字段不会被隐藏。操作列固定在右侧；需要查看更多字段时打开详情或展开区域。
