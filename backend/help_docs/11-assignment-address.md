# 任务分配与小区匹配

## 地址匹配状态

平台保留任务原始地址，并使用本地规则生成小区和社区建议：

- **自动匹配**：唯一、有效且没有街道或社区冲突，可直接参与分配；它不是人工确认，但管理员仍可在详情中纠正。
- **已人工确认**：管理员纠正后的最终结果，优先级最高。
- **多候选待确认**：多个小区接近，暂不能自动分配。
- **地址冲突**：街道、社区或小区归属相互矛盾。
- **未匹配/无效地址**：信息不足或内容明显不是住宅地址。

系统不会因为地址格式不标准就直接判错，也不会覆盖原始地址。错别字、简称、栋幢写法等只用于生成建议。

## 按小区筛选并分配

1. 进入分配工作台。
2. 先选择社区，再选择该社区下的小区。
3. 可继续选择匹配状态或输入地址关键词。
4. 勾选任务后选择单人分配或平均分配。
5. 查看成功、跳过和失败明细。

只有社区和小区归属可靠、来源唯一的任务可以进入平均分配。多候选、冲突、未匹配、停用小区和来源异常任务会被明确跳过。

## 取消错误分配

如果误用平均分配造成数据混乱，具备权限的人员可以使用“取消已分配数据”恢复未分配状态，再按社区、小区重新筛选和分配。取消前应确认任务尚未被核查，避免覆盖已经产生的有效工作。

## 所内移交

结果为“移交（所内）”时，基础管控可选择目标正式社区：

- 目标社区只有一名在岗组长时，系统自动选择该组长。
- 有多名组长时必须明确选择。
- 没有在岗组长时不能提交，应先维护人员配置。

任务会进入接手组长的当前待办，但在线汇总中的有效工作量仍归第一次核查该任务的人员。
