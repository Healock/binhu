# 待登记与拟登记房屋

## “待登记”和“已登记”是什么意思

- **待登记**：本次核查确认人员需要办理登记，但平台还没有完成有效登记核验。选择后必须同时关联辖区档案中的唯一拟登记房屋；它属于“已核查但未完成”，不会立即计入完成任务。
- **已登记**：居住证平台确认登记有效，且登记地址与关联房屋唯一精确匹配。系统需在两个独立扫描周期连续确认后自动改为“已登记”，随后才按已完成任务统计。

“待登记”不是“已登记”的手工替代项，也不能用自由填写的地址冒充房屋关联。

## 操作步骤

1. 在核查结果中选择“待登记”。
2. 页面将“核查补充信息”切换为“拟登记住址”。
3. 输入标准地址的一部分进行模糊搜索。
4. 从辖区档案中明确选择唯一房屋。
5. 核对标准地址、幢室和户号摘要后提交。

待登记结果和房屋关联必须一次保存。没有选择唯一房屋时不能用手工地址冒充关联，也不能先保存一个缺少房屋的待登记结果。

## 找不到房屋怎么办

- 有房屋维护权限：先到“辖区档案”建立或修正房屋，再回来选择。
- 没有维护权限：联系档案维护人员处理。
- 不确定是哪套房屋：不要随意选择相似地址，保留任务并核实。

## 自动确认

居住证平台是只读外部来源。系统只有在登记有效、地址与关联房屋唯一精确匹配，并在两个独立扫描周期连续得到相同结果后，才会自动改为“已登记”。第一次匹配只显示等待再次确认，不会立即完成。

地址不一致、多房同址、房屋停用、社区冲突或查询为空时，任务继续保持待登记并进入复核，不会替换网格员选择的房屋。
