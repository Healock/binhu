# 待登记与拟登记房屋

## “待登记”和“已登记”是什么意思

- **待登记**：本次核查确认人员需要办理登记，但平台还没有完成有效登记核验。填写非空现住址即可保存，不要求标准地址格式或先选择档案房屋；它属于“已核查但未完成”，不会立即计入完成任务。
- **已登记**：居住证平台确认登记有效，且登记地址与关联房屋唯一精确匹配。系统需在两个独立扫描周期连续确认后自动改为“已登记”，随后才按已完成任务统计。

“待登记”不是“已登记”的手工替代项。自由填写的地址不会自动变成房屋关联，也不会因此自动确认已登记。

## 操作步骤

1. 在核查结果中选择“待登记”。
2. 页面将地址字段显示为“现住址”，可以直接填写或修改。
3. 离开地址输入框后自动保存，待登记结果和地址在同一个本地事务中提交。
4. 如需居住证自动确认，可在可选的房屋搜索框中搜索并主动选择当前任务社区的对应房屋。
5. 主动选择房屋会填入该房屋地址，并将结果、地址、房屋编号和版本一次保存。仅找到候选不会替换已填写的地址。

房屋搜索无结果或暂时失败不影响自由地址保存。已选择房屋后再手工修改地址，会取消此次房屋关联，按自由地址保存；需要自动确认时可重新关联。空白地址不能保存。

## 找不到房屋怎么办

- 可以先填写实际地址保存待登记，不必等待房屋建档。
- 需要自动确认且有房屋维护权限：到“辖区档案”建立或修正房屋，再回来选择。
- 没有维护权限：联系档案维护人员处理，处理后重新搜索并关联。
- 不确定是哪套房屋：不要随意选择相似地址，保留自由地址并核实。

## 自动确认

居住证平台是只读外部来源。未关联房屋的自由地址仅作为待建档信息保留，不进入自动确认。系统只有在登记有效、地址与关联房屋唯一精确匹配，并在两个独立扫描周期连续得到相同结果后，才会自动改为“已登记”。第一次匹配只显示等待再次确认，不会立即完成。

地址不一致、多房同址、房屋停用、社区冲突或查询为空时，任务继续保持待登记并进入复核，不会替换网格员选择的房屋。
