# 下发任务处理

下发任务分为原始数据审核和基础管控已处理数据直发两种导入模式。所有发布都进入本地任务池，不再写入腾讯表格。

## 上传与预览

1. 进入“数据上传中心”。
2. 选择对应业务和导入模式。
3. 上传 XLS 或 XLSX 文件并等待预览。
4. 查看有效记录、待研判记录和错误原因。
5. 确认导入后进入下发任务工作台。

缺少手机号、未知社区、未知状态、同批身份证重复或地址冲突的数据不能绕过审核。

## 审核

在下发工作台逐条核对姓名、身份证号、手机号、地址、社区和登记情况。需要修改时使用页面字段；重复人员必须在同一重复组中明确选择保留项。

## 发布

1. 进入选择模式。
2. 逐卡勾选，或使用“全选当前筛选”覆盖所有分页。
3. 确认选中数量和筛选条件。
4. 提交发布并查看逐条结果。

平台不会恢复“整批无条件发布”。任一任务状态、版本或必要字段在发布前变化，整次请求会停止并提示重新核对。

## 批次详情和反馈

批次详情用于历史倒查、发布异常处理和反馈文件导出。反馈文件只包含业务需要的信息，不应携带无关敏感字段。

超级管理员可以撤销尚未成功下发的批次：

- 待审核、待发布、可重试或内容冲突的记录会随批次一起清理；
- 内容冲突只表示本地任务池已有同主键但内容不同的数据，撤销批次不会修改那条现有数据；
- 如果本批次已有任务成功进入本地任务池，平台会禁止整体撤销，避免误删已经下发的业务任务；
- 后台发布仍在运行时，需要等待处理结束并刷新页面后再撤销。
