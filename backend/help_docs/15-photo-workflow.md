# 调照片与工单中心

## 调照片

“调照片”显示当前需要处理的照片待办。基础管控及具备相应权限的人员可以：

1. 按社区、来源或关键词筛选。
2. 领取单条或批量领取待办。
3. 在数据上传中心上传照片 ZIP 并预览匹配结果。
4. 确认导入后查看匹配、未匹配、冲突和重复文件数量。

照片文件名应能安全定位到对应工单。无法定位、同一人员多工单或来源已经结束时，系统会进入人工提示，不会把照片随意挂到其他任务。

## 工单中心

工单中心用于查看自己创建、领取或有权管理的工单。常见操作包括：

- 创建工单；
- 领取待办步骤；
- 填写处理决定或补充说明；
- 上传和查看附件；
- 转交、撤回或恢复队列；
- 查看事件和评论。

工单有版本控制。其他人更新后继续提交旧页面内容会提示冲突，需要刷新后再处理。

## 附件安全

- 只上传与当前工单直接相关的文件。
- 不要把附件内容复制到普通日志或公告。
- 删除附件需要相应权限，历史事件仍保留必要审计信息。
