# 离线模式与居住登记批量查询

## 离线模式的含义

离线模式只表示滨湖智慧平台服务器暂时不可访问。客户端仍需能够访问居住证系统，名单和查询结果只在当前客户端内处理，不会上传到滨湖平台。

## 配置居住证系统

在离线模式页面的“居住证系统配置”中填写或修改接口地址、统一登录密码、MAC 服务地址和请求超时。每个选中社区都要在当前客户端填写该社区自己的完整登录账号；组织代码只作为对应账号的查询回退，不再根据代码自动拼接账号。

在线平台成功读取配置后，客户端会自动缓存接口、MAC、超时、启用状态以及选中社区的 ID、名称和非敏感组织代码；出于安全边界，账号、统一密码和会话不会从平台配置接口返回，离线页面需要由使用者在当前客户端逐社区填写账号并填写统一密码。也可以在离线页面手动刷新在线配置。在线管理员先在“社区管理”中为各社区填写完整账号，再在系统设置中选择后台只读查询范围。离线端会为范围中的每个社区建立独立账号槽位和独立会话，删除已不在远端范围内的槽位，并保留范围内已经在本机填写的账号。保存后的账号和密码只在当前客户端使用，不会写回滨湖平台。

## 批量查询

1. 将 `.xlsx` 文件拖入“已撤管人员居住登记情况批量查询”面板。
2. 确认文件中存在“身份证号”“身份证号码”或“身份证”列。系统不校验身份证号格式，只把该列的原始文本逐行发送查询。
3. 点击“确认并开始查询”。进度面板显示总人数、已完成数量和查询成功人数。
4. 查询完成后点击“导出结果 XLSX”。结果保留原表数据，并在身份证号列后新增“登记情况”列。

“已注销”“未注销”“状态待核对”和“未登记”是居住证系统返回或根据只读响应识别的状态。网络、登录或配置问题会标记为“查询失败”或配置提示，不会阻塞其他行继续处理。

## 数据边界

客户端只调用居住证系统的验证码读取、登录、常住人口预检索和流动人口登记查询只读接口，不执行登记、注销、写回或删除操作。居住证查询需要系统允许当前客户端跨域访问；若浏览器环境拦截跨域请求，请使用已配置的桌面客户端或先由管理员核对居住证系统访问策略。
