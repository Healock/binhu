# 离线模式与居住登记批量查询

## 离线模式的含义

离线模式只表示滨湖智慧平台服务器暂时不可访问。客户端仍需能够访问居住证系统，名单和查询结果只在当前客户端内处理，不会上传到滨湖平台。

## 配置居住证系统

在离线模式页面的“居住证系统配置”中填写或修改接口地址、统一登录密码、要使用的本机 MAC 地址和请求超时。每个选中社区都要在当前客户端填写该社区自己的完整登录账号；组织代码只作为对应账号的查询回退，不再根据代码自动拼接账号。MAC 地址支持连续十六进制、冒号、连字符和点号输入，客户端会规范化为大写冒号格式。

在线平台成功读取配置后，客户端会自动缓存接口、超时、启用状态以及选中社区的 ID、名称和非敏感组织代码；出于安全边界，账号、统一密码、本机 MAC 和会话不会从平台配置接口返回，离线页面需要由使用者在当前客户端逐社区填写账号、统一密码并确认本机 MAC。也可以在离线页面手动刷新在线配置。在线管理员先在“社区管理”中为各社区填写完整账号，再在系统设置中选择后台只读查询范围。离线端会为范围中的每个社区建立独立账号槽位和独立会话，删除已不在远端范围内的槽位，并保留范围内已经在本机填写的账号。保存后的账号、密码和本机 MAC 只在当前客户端使用，不会写回滨湖平台。

## 批量查询

1. 将 `.xlsx` 文件拖入“已撤管人员居住登记情况批量查询”面板。
2. 确认文件中存在“身份证号”“身份证号码”或“身份证”列。系统不校验身份证号格式，只把该列的原始文本逐行发送查询。
3. 点击“确认并开始查询”。进度面板显示总人数、已完成数量和查询成功人数。
4. 查询完成后点击“导出结果 XLSX”。结果保留原表数据，并在身份证号列后新增“登记情况”列。

“已注销”“未注销”“状态待核对”和“未登记”是居住证系统返回或根据只读响应识别的状态。网络、登录或配置问题会标记为“查询失败”或配置提示，不会阻塞其他行继续处理。

## 配置本机 MAC

Windows 客户端首次启动时会读取一次本机硬件网卡 MAC，作为默认地址保存，并在本机 `127.0.0.1:23333` 提供兼容读取端口。点击“读取当前 MAC”可查看当前电脑实际使用的地址；填写后点击“保存本机 MAC”，客户端会保存并回读核对。端口被其他程序占用或回读不一致时，页面会明确提示。

页面可以维护多个候选 MAC。将地址加入候选列表后，可以切换当前地址，也可以逐个或一次检测全部候选。检测会单路依次使用当前客户端已经填写的社区账号登录，最多检查 12 个社区账号，并展示每个 MAC 可以登录的社区。检测结果、社区账号、密码和候选 MAC 都只保存在当前客户端；检测不会执行登记、开户、删除或写回。若账号或统一密码本身错误，对应社区也会显示为不可登录，应先核对账号配置再判断 MAC 是否已认证。

本机端口只绑定回环地址，不接受网络中的其他电脑访问，也不提供 HTTP 写入。离线页面通过客户端内部受控接口修改地址。客户端只把当前地址或正在检测的候选地址放入居住证登录请求，它不会成为滨湖业务数据源。

## 数据边界

客户端只调用居住证系统的验证码读取、登录、常住人口预检索和流动人口登记查询只读接口，不执行登记、注销、写回或删除操作。居住证查询需要系统允许当前客户端跨域访问；若浏览器环境拦截跨域请求，请使用已配置的桌面客户端或先由管理员核对居住证系统访问策略。
