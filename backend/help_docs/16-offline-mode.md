# 离线模式与居住登记批量查询

## 离线模式的含义

离线模式只表示滨湖智慧平台服务器暂时不可访问。客户端仍需能够访问居住证系统，名单和查询结果只在当前客户端内处理，不会上传到滨湖平台。

## 配置居住证系统

在离线模式页面的“离线模式设置”侧边栏中填写或修改接口地址、统一登录密码、要使用的本机 MAC 地址和请求超时。接口地址可以包含居住证平台的应用上下文路径，例如 `https://example.invalid/grandlynn-boot`；客户端会把验证码和登录请求发送到该路径下。每个选中社区都要在当前客户端填写该社区自己的完整登录账号；组织代码只作为对应账号的查询回退，不再根据代码自动拼接账号。MAC 地址支持连续十六进制、冒号、连字符和点号输入，客户端会规范化为大写冒号格式。

在线平台成功读取配置后，已授权客户端会缓存接口、超时、启用状态、选中社区的 ID、名称、组织代码及该社区已配置的完整登录账号；统一密码、本机 MAC 和会话令牌不会从平台配置接口返回。使用者仍需在当前客户端填写统一密码并确认本机 MAC，也可以手动刷新在线配置。在线管理员先在“社区管理”中为各社区填写完整账号，再在系统设置中选择后台只读查询范围。离线端会为范围中的每个社区建立独立账号槽位和独立会话，删除已不在远端范围内的槽位，并保留范围内已经在本机填写的账号。本机保存操作不会把账号、密码或 MAC 写回滨湖平台。

## 批量查询

离线模式的“批量查询”侧边栏包含两个互相独立的面板。每个面板都有自己的文件上传区、进度、失败分类和导出结果；两个功能不会共用已选择的文件或查询状态。

1. 将已撤管人员名单 `.xlsx` 文件拖入“已撤管人员居住登记情况批量查询”面板。
2. 确认文件中存在“身份证号”“身份证号码”或“身份证”列。客户端会去除空白和前导单引号，校验 15/18 位身份证号及日期、校验位；格式无效的行直接标记为“身份证号格式无效”，不会发送到居住证系统。Excel 中请把身份证列设置为文本，避免数值单元格丢失前导位或变成科学计数法。
3. 点击“查询登记情况”。进度面板显示总人数、已完成数量和查询成功人数。
4. 查询完成后点击“导出结果 XLSX”。结果保留原表数据，并在身份证号列后新增“登记情况”列。

将涉警人员信息名单 `.xlsx` 文件单独拖入“涉警人员信息登记地址批量查询”面板，再点击“查询登记地址”。不要复用已撤管人员面板中的文件。该操作沿用相同的身份证校验、社区账号隔离和只读查询链路；完成后导出的文件会在原工作表最后追加“登记地址”列，保留原有工作表、样式、列宽、筛选和冻结表头。再次导入已有“登记地址”列的结果文件时会更新原列，不再追加同名列。居住证平台没有登记、上游缺少地址或本行查询失败时，该列保持空白，需结合页面失败分类复核，不会把错误信息写入地址列；重新查询失败时旧地址不会被当作本次有效结果保留。

如果名单读取失败，页面会区分具体原因：文件不是可解析的 XLSX、工作簿缺少或无法解析工作表、未找到支持的身份证号表头，或表头后没有可处理的数据行。请按提示用 Excel/WPS 另存为 `.xlsx`、修正表头或补充数据后重试；不会显示 XML 原文、身份证号、地址或居住证响应正文。

“已注销”“未注销”“状态待核对”和“未登记”是居住证系统返回或根据只读响应识别的状态。“身份证号格式无效”表示输入未通过本地校验；网络、登录或配置问题会标记为“查询失败”或配置提示，不会阻塞其他行继续处理。

## 配置本机 MAC

Windows 客户端首次启动时会读取一次本机硬件网卡 MAC，作为默认地址保存，并在本机 `127.0.0.1:23333` 提供兼容读取端口。点击“读取当前 MAC”可查看当前电脑实际使用的地址；填写后点击“保存本机 MAC”，客户端会保存并回读核对。端口被其他程序占用或回读不一致时，页面会明确提示。

页面可以维护多个候选 MAC。将地址加入候选列表后，可以切换当前地址，也可以逐个或一次检测全部候选。检测会单路依次使用当前客户端已经填写的社区账号登录，最多检查 12 个社区账号，并展示每个 MAC 可以登录的社区。Windows 桌面客户端优先通过本机受控网络桥接访问验证码和登录只读接口，绕过浏览器的 CSP、CORS 和证书校验限制；探测不会保存登录令牌，也不会调用登记、开户、删除或写回接口。

检测结果会区分“允许访问”“账号或 MAC 未通过登录”“网络/证书探测失败”和“配置不完整”。只有收到有效登录令牌才计入允许访问；网络、TLS、CSP、CORS 或接口暂时不可达时会显示为“无法判定”，不能把它误认为 MAC 未授权。若全部账号都是“无法判定”，先检查桌面客户端网络权限、接口地址和居住证平台连通性，再判断 MAC 是否已认证。若明确显示未通过登录，再核对该社区完整账号和统一密码。

本机端口只绑定回环地址，不接受网络中的其他电脑访问，也不提供 HTTP 写入。离线页面通过客户端内部受控接口修改地址。客户端只把当前地址或正在检测的候选地址放入居住证登录请求，它不会成为滨湖业务数据源。

## 数据边界

客户端只调用居住证系统的验证码读取、登录、常住人口预检索和流动人口登记查询只读接口，不执行登记、注销、写回或删除操作。登记地址批量查询只从流动人口登记响应的登记地址字段生成用户主动导出的文件，不把地址写入滨湖平台、日志、诊断或审计。居住证查询需要系统允许当前客户端跨域访问；若浏览器环境拦截跨域请求，请使用已配置的桌面客户端或先由管理员核对居住证系统访问策略。

## 在线配置同步与诊断

离线页面的“刷新在线配置”只在已登录且有权限时读取平台为所选社区保存的完整登录账号；统一密码、居住证会话令牌和本机 MAC 仍只保存在当前客户端。使用带应用上下文路径的地址时，例如 `https://example.invalid/grandlynn-boot`，验证码、登录和批量查询都会沿用该路径。

Windows 客户端会通过受限的原生只读请求桥访问居住证平台，桥只允许验证码、登录、常住人口预检索和流动人口登记查询四条路径，不允许登记、修改、删除或写回。浏览器环境没有该桥时才使用浏览器跨域请求。

在“离线模式设置”区域可以点击“导出诊断信息”。诊断文件只包含地址来源、路径、配置是否存在、账号数量、社区名称、脱敏 MAC、授权检测摘要和两个批量查询面板各自的错误码计数，不包含密码、令牌、Cookie、完整 MAC、身份证号或居住证响应正文。批量查询失败时，页面会按网络、响应、HTTP、认证或业务错误分类显示，便于排查证书、应用上下文路径和平台权限。
