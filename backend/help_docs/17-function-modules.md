# 功能模块与单位权限

## 访问规则

页面是否可用由模块归属和原有功能权限共同决定，两者是 AND 关系。公共模块面向所有登录账号；社区警务模块只对关联社区部门的人员开放。管理员和超级管理员可以跨单位查看，但仍受页面原有功能权限限制。

桌面侧栏、手机导航和直接页面访问使用启动接口返回的可用模块集合。隐藏导航只是界面行为，后端接口仍会检查模块归属和原有权限。

## 看不到功能时

常见原因有三类：模块归属单位与账号部门不符、权限组没有授予该页面所需权限，或模块当前已停用。请联系管理员核对人员关联部门、权限组和模块设置；调整后重新登录或刷新页面。

模块定义变更会保存版本快照，便于管理员核对模块归属变化记录。
