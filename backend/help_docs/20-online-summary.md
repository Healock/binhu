# 仪表盘与在线数据汇总

## 仪表盘

仪表盘按岗位展示常用入口、待办数量和业务概览。卡片数字用于快速发现工作，不代替具体任务列表；点击卡片进入明细后，以明细筛选结果为准。

“社区完成情况”图形根据当前统计口径展示各社区进度。图形为空时先确认日期范围、业务类型和数据权限，不要仅凭空图判断数据已丢失。

## 在线数据汇总

页面直接展示：

- 网格员汇总表；
- 社区汇总表；
- 与当前日期、业务类型和社区筛选对应的总计。

无需在两种布局之间切换。网格员表和社区表各出现一次，指标使用同一套统计口径。

启用外部腾讯表只读监控后，页面会另外显示“外部腾讯表监控”：

- 当前外部行数；
- 所选日期内的外部新增、内容变化和移除数量；
- 最近一次成功读取时间，以及过期或读取失败提示。

外部监控与平台任务汇总分开显示。外部行不会导入平台，不会进入网格员工作量、待完成、已完成、核查率或见底率，也不会因为平台编辑而回写腾讯表。首轮成功读取只建立比较基线，不会把现有全部行显示为新增；后续新增、内容变化和移除是所选日期内各轮读取相对上一成功快照的累计变化次数，腾讯表单纯调整行顺序不计变化。读取失败时页面保留最后一次成功结果并标明截至时间，不会把失败显示成 0，也不会影响本地业务统计。

超级管理员可以通过“配置外部监控”进入配置页面，设置固定腾讯表链接、数据子表、解析类型和自动读取间隔，也可以点击“立即读取一次”。配置页面只保存只读监控所需凭据，Token 加密保存且不会回显；普通用户看不到入口。该页面不会恢复腾讯业务同步、任务导入、写回、删除或旧 OAuth 管理，Dev、Staging 和 Shadow 环境禁止启用。

## 工作量口径

- 同一任务按有效业务活动去重。
- 普通分配本身不增加网格员工作量。
- 所内移交后，当前待办属于接手人，但有效工作量仍归第一核查人和第一社区。
- 研判及延时期间属于已核查未完成；最终结果形成后按对应业务规则统计。

## 导出

导出文件遵循当前账号权限、日期范围、业务类型、筛选和排序。导出不会扩大到页面外的数据范围，也不会改变任务状态。
