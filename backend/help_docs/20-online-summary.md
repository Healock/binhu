# 仪表盘与在线数据汇总

## 仪表盘

仪表盘按岗位展示常用入口、待办数量和业务概览。卡片数字用于快速发现工作，不代替具体任务列表；点击卡片进入明细后，以明细筛选结果为准。

“社区完成情况”图形根据当前统计口径展示各社区进度。图形为空时先确认日期范围、业务类型和数据权限，不要仅凭空图判断数据已丢失。

## 在线数据汇总

页面直接展示：

- 网格员汇总表；
- 社区汇总表；
- 与当前日期、业务类型和社区筛选对应的总计。

无需在两种布局之间切换。网格员表和社区表各出现一次，指标使用同一套统计口径。

启用外部腾讯表只读监控后，页面会保留“外部腾讯表监控”状态卡，并把已经按下发日期和任务状态归类的外部只读计数叠加到同一份在线汇总和统计表：

- 当前外部行数；
- 所选日期内的外部新增、内容变化和移除数量；
- 最近一次成功读取时间，以及过期或读取失败提示。

叠加只发生在展示层：外部行不会导入平台业务表、不会进入本地任务流水、日报流水或工作贡献事件，也不会因为平台编辑而回写腾讯表。脱敏统计桶只保存社区、核查人、下发日期、任务状态和数量；核查人是平台内部人员维度，用于观察各核查人的任务完成情况。统计桶不保存任务对象的姓名、身份证号、手机号、地址、备注、研判正文、照片、附件、完整行内容或腾讯物理行号。社区统计表会把外部计数并入对应社区并重新计算合并后的完成率；核查人表按腾讯表中已有的“核查人”字段分组，同社区同名的本地核查人与外部核查人合并为一行，未填写核查人的记录显示为“未指定核查人（腾讯只读）”，不会伪造具体人员。在线汇总中的任务总数、结转、新下发、已有任务变化、待完成和已完成会包含外部观察计数，并在响应中保留 `external_overlay` 来源标记；即使本地日报尚未生成，只要已有成功外部快照，接口也会返回只包含外部观察数据的社区及核查人统计结果。首轮成功读取只建立比较基线，不会把现有全部行显示为新增；后续新增、内容变化和移除是所选日期内各轮读取相对上一成功快照的累计变化次数，腾讯表单纯调整行顺序不计变化。读取失败时页面保留最后一次成功结果并标明截至时间，不会把失败显示成 0，也不会阻塞本地业务统计。

超级管理员可以通过“配置外部监控”进入配置页面。一个只读连接可以配置多个监控目标，每个目标分别填写腾讯表链接、数据子表（链接中的 `tab` 参数可直接作为子表 ID）、解析类型、表头行和自动读取间隔，并可单独启停或移除。Client ID、Access Token 和 Open ID 必须来自同一次腾讯授权，完整填写后点击“保存连接凭据”；Token 加密保存且不会回显。保存监控目标不会隐式保存凭据，填写凭据后也不能跳过保存直接执行“立即读取一次”。Production 中保存凭据或目标启用状态后立即生效，无需部署人员修改环境变量或重启 backend；“立即读取一次”和定时读取使用相同的数据库配置。Development、Staging 和 Shadow 环境由后端硬性禁止启用。该页面不会恢复腾讯业务同步、任务导入、写回、删除或旧 OAuth 管理。

外部监控解析类型包括“疑似漏登记”和“疑似未注销模型三”。“疑似未注销模型三”目标使用已确认的腾讯表链接及其 `BB08J2` 子表；两个目标都与其他只读目标共享同一套已配置凭据。链接仍由超级管理员在 Production 配置页面保存，仓库不硬编码凭据或启用状态。监控只生成社区/核查人统计桶，不会把外部行写入平台业务表。

## 工作量口径

- 同一任务按有效业务活动去重。
- 普通分配本身不增加网格员工作量。
- 所内移交后，当前待办属于接手人，但有效工作量仍归第一核查人和第一社区。
- 研判及延时期间属于已核查未完成；最终结果形成后按对应业务规则统计。

## 导出

导出文件遵循当前账号权限、日期范围、业务类型、筛选和排序。导出不会扩大到页面外的数据范围，也不会改变任务状态。
