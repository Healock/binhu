# 走访与平安码/管家码汇总

## 走访汇总

走访汇总按日期、人员、社区和岗位统计走访情况。数据来自平台配置的只读走访来源，平台不向来源系统写入。读取和确认入口统一位于“数据上传中心 → 读取外部”；汇总页面只负责查看和导出。

使用步骤：

1. 选择日期范围。
2. 选择社区、人员或其他筛选条件。
3. 查看总计和明细。
4. 需要文件时按当前筛选导出。

日期面板支持翻月和按月份、年份跳转；后台会话刷新不会改变正在浏览的月份或尚未选完的日期范围。只读获取的业务日期范围与下方汇总查询的日期范围相互独立。

房屋档案列表只显示最近走访日期和最近星级评定，具体历史、次数和明细需进入房屋详情查看。

## 平安码/管家码汇总

页面按日期展示并整理平安码、管家码数据，同时显示位置分类、新增登记和相关业务统计。来源读取统一从“数据上传中心 → 读取外部”发起；手动读取前可选择业务日期范围，默认读取前一业务日，单次最多 31 天。自动调度的日期参数独立于本次手动读取。

位置无法识别时会先纳入汇总，并以绿色提示显示未分类地点数量；具备权限的人员可维护“地点分类”后重新计算。身份无效或时间无效仍会阻止自动提交，以免不可靠记录覆盖现有汇总。运行记录仅显示各来源的总量、有效量、无效记录数、未分类地点数和无效时间数。

“产生指令数”包含“地址待变更”，不会因为任务需要修正地址而漏计。这个指标表示产生的指令数量，不等于已完成数量。

## 数据为空时

先检查：

- 日期是否有来源数据；
- 来源获取任务是否成功；
- 当前账号是否有对应社区数据范围；
- 时间字段是否有效。

不要通过制造真实上游数据来测试汇总；生产验收应使用自然产生的数据或只读核对。
