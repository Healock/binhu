# 走访与平安码/管家码汇总

## 走访汇总

走访汇总按日期、人员、社区和岗位统计走访情况。数据来自平台配置的只读走访来源，平台不向来源系统写入。

使用步骤：

1. 选择日期范围。
2. 选择社区、人员或其他筛选条件。
3. 查看总计和明细。
4. 需要文件时按当前筛选导出。

房屋档案列表只显示最近走访日期和最近星级评定，具体历史、次数和明细需进入房屋详情查看。

## 平安码/管家码汇总

页面按日期获取并整理平安码、管家码数据，同时显示位置分类、新增登记和相关业务统计。位置无法识别时进入“未分类”，具备权限的人员可维护位置分类后重新计算。

## 数据为空时

先检查：

- 日期是否有来源数据；
- 来源获取任务是否成功；
- 当前账号是否有对应社区数据范围；
- 时间字段是否有效。

不要通过制造真实上游数据来测试汇总；生产验收应使用自然产生的数据或只读核对。
