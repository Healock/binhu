# 文件生成与工作日志

“文件生成”用于把系统统计和人工填写内容合并为工作日志及相关文件。

## 创建草稿

1. 选择业务日期和日志类型。
2. 读取系统已计算的人员、任务、走访和社区数据。
3. 填写需要人工补充的文字、数字或表格。
4. 保存草稿并检查必填项。
5. 生成 PDF 或页面提供的其他文件。

## 数据来源

- 系统字段来自对应日期的统计快照。
- 人工字段只保存当前草稿内容。
- 没有完整历史快照的日期可能留空或提示参考，不会用当前数据伪装历史。

## 草稿管理

草稿列表可以按日期和类型查找。多人处理同一草稿时应注意版本变化，避免用旧页面覆盖他人修改。

## 生成前检查

- 人员数量、社区顺序和日期是否正确；
- 请假、周末备勤等状态是否符合实际；
- 手工备注是否含不必要的敏感信息；
- 表格是否存在空白必填项或异常数字。
