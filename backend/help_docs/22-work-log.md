# 文件生成与工作日志

“文件生成”用于把系统统计和人工填写内容合并为工作日志及相关文件。

## 创建草稿

1. 选择业务日期和日志类型。
2. 读取系统已计算的人员、任务、走访和社区数据。
3. 填写需要人工补充的文字、数字或表格。
4. 保存草稿并检查必填项。
5. 生成 PDF 或页面提供的其他文件。

## 数据来源

- 系统字段来自对应日期的统计快照。
- 人工字段只保存当前草稿内容。
- 没有完整历史快照的日期可能留空或提示参考，不会用当前数据伪装历史。

## 草稿管理

草稿列表可以按日期和类型查找。多人处理同一草稿时应注意版本变化，避免用旧页面覆盖他人修改。

## 生成前检查

- 人员数量、社区顺序和日期是否正确；
- 请假、周末备勤等状态是否符合实际；
- 手工备注是否含不必要的敏感信息；
- 表格是否存在空白必填项或异常数字。

## 工作每日明细

每日明细使用附件版式生成 18 列 XLSX，业务板块为“流动人口”“入户走访”“指令核查”。选择业务日期后，在社区表中填写流动人口新增和注销，保存成功后才能生成文件；空白不会按零计算。目标数按当天在岗组长、组员人数乘文件生成页填写的目标系数计算，缺勤人员的业务数值显示“/”。

“管家码”岗位不属于社区或片区，导出时单独列出且不参加社区统计。出租房、自购房目标和流动人口目标系数都在文件生成页填写，并按当前账号保存；流动人口目标系数默认 10。历史日期没有日报快照时保持为空。

每日明细不展示社区民警、所队领导、中队长和基础管控。片长姓名只显示在片区名称下方；自购房人员在人员管理中指定片区后，导出到该片区的“自购房”行。

同一片区内的“自购房”行固定排在该片区最后。户均变动数和核查见底率等小数列统一按两位小数显示。指令下发数取当天在线数据汇总的“数据总数”，核查指令数取“已核查＋已完成”，完成指令数取“已完成”。每日明细按个人统计：同一姓名在名册中唯一时，合并其当天所有社区的在线任务，并按合计分子、分母重算核查见底率；名册中存在同名人员时按社区精确匹配，来源记录重复或无法唯一匹配时保持空白，不把其他人员的数据带入。

指令统计与在线数据汇总使用相同口径，包含该业务日期可用的本地日报和已保存的外部只读监控统计。生成文件只读取已保存统计，不触发外部表读取，也不会用当前在线任务补造历史日报。核查见底率（包括合计）为“已完成÷（已完成＋无法见底数）”，不是“核查指令数÷下发数”；缺少可靠分母时合计留空。

导出颜色按完成情况标注：流动人口目标大于零且新增、注销均已填写时，两格按合计完成比例显示低于 50% 淡红、50% 至低于 100% 淡黄、达到 100% 淡绿。入户走访目标大于零且走访数已填写时，“入户走访数”不超过目标的 50% 标淡黄，超过 50% 标淡绿；指令下发数大于零且核查数已填写时，“核查指令数”不超过下发数的 50% 标淡黄，超过 50% 标淡绿。缺勤、管家码、未填数据、零目标和合计行不着色。
