# 文件生成与工作日志

“文件生成”用于把系统统计和人工填写内容合并为工作日志及相关文件。

## 创建草稿

1. 选择业务日期和日志类型。
2. 读取系统已计算的人员、任务、走访和社区数据。
3. 填写需要人工补充的文字、数字或表格。
4. 保存草稿并检查必填项。
5. 生成 PDF 或页面提供的其他文件。

## 数据来源

- 系统字段来自对应日期的统计快照。
- 人工字段只保存当前草稿内容。
- 没有完整历史快照的日期可能留空或提示参考，不会用当前数据伪装历史。

## 草稿管理

草稿列表可以按日期和类型查找。多人处理同一草稿时应注意版本变化，避免用旧页面覆盖他人修改。

## 生成前检查

- 人员数量、社区顺序和日期是否正确；
- 请假、周末备勤等状态是否符合实际；
- 手工备注是否含不必要的敏感信息；
- 表格是否存在空白必填项或异常数字。

## 工作每日明细

每日明细使用附件版式生成 18 列 XLSX。选择业务日期后，在社区表中填写流动人口新增和注销，保存成功后才能生成文件；空白不会按零计算。目标数按当天在岗组长、组员人数乘系统设置中的目标系数计算，缺勤人员的业务数值显示“/”。

“管家码”岗位不属于社区或片区，导出时单独列出且不参加社区统计。出租房、自购房目标和流动人口目标系数都在文件生成页填写，并按当前账号保存；流动人口目标系数默认 10。历史日期没有日报快照时保持为空。

每日明细不展示社区民警、所队领导、中队长和基础管控。片长姓名只显示在片区名称下方；自购房人员在人员管理中指定片区后，导出到该片区的“自购房”行。

同一片区内的“自购房”行固定排在该片区最后。户均变动数和核查见底率等小数列统一按两位小数显示。指令下发数取当天在线数据汇总的“数据总数”，核查指令数取“已核查＋已完成”，完成指令数取“已完成”；人员明细优先按正式社区和姓名匹配，无法唯一匹配时保持空白，不把其他社区的同名人员数据带入。
