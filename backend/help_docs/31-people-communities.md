# 人员、社区与小区管理

## 人员管理

人员管理保存姓名、岗位、联系方式、所属部门、在岗状态和出勤信息。修改人员前要确认是否已经关联账号；删除或改绑可能影响任务权限、统计归属和个人资料。

常用操作：

- 按姓名或电话搜索；
- 维护岗位、社区和部门；
- 记录请假、离岗和周末备勤；
- 查看个人资料和贡献日历；
- 由超级管理员维护身份证信息等敏感字段。

## 社区管理

社区决定任务数据范围、人员归属和小区归属。停用社区前要检查是否仍有在办任务、房屋、小区或人员关联。

## 小区管理

小区地址库维护：

- 标准小区名；
- 别名和历史名称；
- 标准地址片段；
- 所属街道和社区；
- 有效状态。

任务地址和房屋地址会用该地址库生成匹配建议。同名小区、跨社区或停用小区需要人工处理；管理员的人工修正不会被后续规则重跑覆盖。
