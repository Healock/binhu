# 场所码管理

场所码用于为辖区场所生成公开登记入口。平台本地数据库是场所和登记记录的唯一正式业务来源；云端 Receiver 只负责在正式切换后接收加密登记并等待平台主动拉取。

## 创建场所码

1. 进入“场所码管理”。
2. 填写场所名称、类型、地址和所属社区。
3. 保存后生成二维码。
4. 下载或展示二维码，使用手机扫码验证公开页面。

正式切换前仍使用平台本地入口。云端同步和主动拉取只有在候选环境、单场所闭环和分批验收全部通过后才会启用，用户不需要自行修改配置。

## 二维码和访问链接

二维码图片由平台接口提供，网页端和桌面客户端使用同一资源地址。若图片不显示：

1. 先尝试打开二维码详情或刷新。
2. 检查当前客户端网络和登录状态。
3. 确认场所仍为启用状态。
4. 仍失败时记录场所名称和错误提示交管理员排查，不要重复创建同名场所。

## 轮换链接

发现二维码链接泄露或需要作废旧码时，可以轮换令牌。轮换后旧二维码立即失效，需要重新下载和张贴。

云端单窗口切换时，现场会按批次打印并替换新二维码。全部场所切换完成后，旧二维码返回“二维码已更换”（HTTP 410），新二维码进入云端登记页。发现扫码失败、重复提交或登记状态长时间未更新时，应保留错误提示并联系管理员，不要重复创建场所或重复提交登记。

## 登记信息

具备权限的人员可以按当前筛选查看或导出场所登记信息。导出只用于规定业务，不得向无关人员转发。
