# 在线数据查询与数据上传中心

## 在线数据查询

“在线数据查询”查询的是本地业务表和本地归档，不再读取腾讯表格。所有具备“查看在线原始数据”权限的账号都可以进入，并按账号的数据范围查看当前或历史数据；查看权限不会自动授予编辑权限。

当前在线数据支持在工作表中编辑有权限的单元格。保存直接进入平台本地业务事务，不会写回腾讯文档；历史归档仍只读。

带下拉箭头的字段使用 Univer 原生选项校验；请从下拉列表选择合法值。工作表会在提交前拒绝不在选项中的自由文本，避免把普通格式错误显示为服务器保存失败。

基础管控、中队长及以上获授权岗位可随时修正疑似返苏、出租房屋核查和涉警数据；普通组长、组员不能通过该入口获得任意时间编辑权限。页面按实际权限展示可编辑字段，研判、归档和房屋关联等结构化操作仍从对应业务入口处理。

工作表优先通过实时连接同步保存结果和版本变化。连接仍在建立或尚未连接且修改尚未发出时，页面会安全地改用普通保存接口；发送后连接中断或保存响应超时时，结果可能已经落库，请先确认该行状态，不要连续重复提交。保存失败会保留失败单元格，并提供重试或重新读取入口。

电脑端工具栏中的“查找”与 `Ctrl+F` 会打开同一个 Univer 原生查找面板。“全屏”只把工作表铺满当前应用内容区，不会让浏览器或桌面程序窗口进入系统全屏；再次点击“退出全屏”即可恢复页面布局。

## 数据上传中心

数据上传中心负责文件上传、预览、确认导入和处理进度，不负责无条件发布。当前常见入口包括：

- 下发任务文件；
- 照片调取 ZIP；
- 自购自住名单等专用导入。

## 上传步骤

1. 选择正确的业务和文件类型。
2. 上传文件后等待后台预览。
3. 查看总数、有效数、冲突数、跳过数和错误原因。
4. 确认无误后执行导入。
5. 根据页面指引前往对应工作台继续审核或处理。

## 超时怎么办

上传或处理超时时，不要立即重复提交多次。先查看后台任务或刷新批次状态，确认是否已经创建任务；只有明确失败且没有成功批次时再重试。

## 文件要求

- 使用页面支持的 XLS、XLSX 或 ZIP 格式。
- 身份证号和手机号应保存为文本，避免科学计数法或丢失前导零。
- 不要在文件中加入公式、密码、无关附件或真实系统凭据。
