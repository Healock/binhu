# 用户、权限与系统管理

## 用户管理

超级管理员可以创建账号、关联人员、调整显示姓名和权限组。账号与人员资料是两层关系：人员记录描述真实岗位和社区，账号决定登录与权限。已关联账号的人员不要随意删除或重复创建。

## 权限组

权限组决定用户能看到哪些菜单、访问哪些接口以及数据范围。修改权限时：

1. 明确岗位需要完成的业务。
2. 只授予必要权限。
3. 同时检查查看、编辑、管理和数据范围。
4. 使用测试账号验证菜单隐藏和后端拒绝都有效。

仅隐藏菜单不等于权限控制，后端必须继续鉴权。

## 公告

具备公告管理权限的人员可以发布重要通知。公告正文应简洁，不包含身份证号、手机号、密码、令牌或业务原始数据。

## 系统设置

系统设置包括维护模式、系统时间、统计岗位和其他平台级配置。启用维护模式前要填写明确说明和时间，维护结束后确认普通账号已经恢复访问。

## 编辑帮助文档

超级管理员进入“帮助”，打开任意文档后点击“编辑 Markdown”：

1. 修改标题、摘要和 Markdown 正文。
2. 在预览页检查标题、列表、表格、链接和代码块。
3. 保存后立即对所有用户生效。
4. 如果要放弃线上修改，可恢复为随版本发布的内置文档。

编辑采用版本校验。其他管理员先保存后，旧页面会提示冲突，不会覆盖新内容。审计只记录文档、版本和字符数量，不记录正文。
