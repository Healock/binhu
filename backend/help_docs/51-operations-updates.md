# 运维中心与客户端更新

## 影子压测环境

影子压测环境只用于管理员组织的并发测试，里面全部是虚构账号和虚构业务数据。普通用户继续使用原账号登录，不需要选择环境。

受邀验收时，在正式 Windows 客户端输入管理员提供的、以 `@shadow` 结尾的专用账号。客户端会自动连接同一平台地址下的影子环境；登录成功后页面顶部持续显示橙色“影子压测环境”提示和本次运行编号。

- 看见橙色提示后才能进行压测操作；没有提示时不要录入压测数据。
- 影子环境未开启时，登录页会明确提示，客户端不会改去正式环境。
- 退出影子账号后，客户端自动恢复普通登录方式。
- 影子环境只允许使用虚构内容，不得输入真实姓名、身份证号、手机号或地址。
- 压测完成后由管理员统一关闭环境；用户不需要删除客户端或修改服务器地址。

## 运维中心

运维中心仅向超级管理员开放，主要用于只读查看：

- 服务和数据库状态；
- 磁盘、连接和近期错误；
- 备份计划与备份任务；
- 后台任务队列；
- 平台拥堵状态、P50/P95/P99 响应速度和并发请求；
- 数据库连接池、MySQL 锁等待和应用线程阻塞信号；
- 后台任务的运行、排队、最久占用时间和任务类型分布；
- 操作记录。

页面不提供任意终端、任意 SQL、数据库恢复或随意重启容器。

### Dev 和预发布环境账号

超级管理员可以在“运维中心 → 环境账号”查看 Dev 与预发布账号的环境、启用状态、首次改密状态、最近登录和最近重置时间。系统不会显示现有密码，因为数据库只保存不可逆密码哈希。

需要重新发放账号时，点击“重置初始密码”，重新输入当前超级管理员密码。系统会在对应隔离环境生成一次性初始密码，并在弹窗中显示一次；关闭弹窗后不能恢复，也不会写入操作记录、日志、URL 或浏览器存储。目标账号下次登录必须修改密码。隔离环境服务不可用时操作会停止，不会回退到生产账号库。

“操作记录”打开后会自动接收新增记录，无需反复手动刷新。筛选仍按当前操作类型生效；切换页面时会关闭实时连接。网络中断后自动重连并补拉，手动刷新仍可重新读取完整分页数据。登录失效或权限撤销时，实时连接会关闭。

实时通知只带安全摘要；完整可查看内容仍以受权限保护的操作记录查询为准。

## 查看性能与拥堵

打开“运维中心 → 性能与拥堵”。顶部会把当前状态归纳为“正常、繁忙、拥堵、恢复中或采集中”。

- 平时重点看 **P95 响应速度**。它比平均值更能反映用户是否遇到卡顿。
- “当前并发请求”表示此刻仍未结束的请求；持续升高通常意味着请求开始排队。
- “事件循环最大阻塞”表示应用线程是否被同步计算或阻塞调用卡住。
- 409 是多人同时修改同一任务产生的版本冲突，单独统计，不算服务端故障。
- “后台任务占用”按运行中和排队任务估算，只用于判断任务池压力，不代表某个任务精确占用了多少 CPU。

页面出现黄色或红色提示时，不会只显示“禁止操作”。每条提示都会说明原因和下一步入口：可以查看最慢接口、打开后台任务、进入数据库状态或查看同一时段系统日志。

性能面板每 5 秒自动刷新，只记录接口模板、请求方式、耗时和状态码，不记录查询内容、姓名、证件号、手机号、地址或业务正文。服务刚重启时样本较少，会暂时显示“采集中”。

## 备份

普通前端更新通常不需要数据库备份；涉及业务表、迁移、统计或同步逻辑时，发布人应按影响范围选择备份。备份成功不等于可以随意恢复，恢复数据库仍需单独确认。

## 客户端更新

桌面客户端在平台发布新版本后检查更新：

1. 打开更新设置或等待自动检查。
2. 确认发现的新版本号和更新日志。
3. 开始更新，优先使用增量包，失败时可回退全量包。
4. 重启后检查版本、登录状态和本地设置。

Win7 与 Win10/11 使用独立更新包和清单，不能交叉使用。

## 常见发布状态

- **主线 CI 通过**：代码检查完成，不代表客户端已发布。
- **版本门禁失败**：客户端代码变化但版本号未提升，重新运行不会解决。
- **更新服务器已发布**：用户更新源已经有新包。
- **GitHub Release 已归档**：审计资产已保存，不是正式更新源。
- **实机已验收**：至少在对应平台完成发现更新、安装和重启检查。

只有更新服务器发布和实机验收完成后，才能通知用户更新。
