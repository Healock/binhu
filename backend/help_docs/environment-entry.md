# 生产、预发布与 Dev 环境入口

正式业务在生产入口处理。预发布入口是 `/staging/`，Dev 入口是 `/dev/`；两个入口只有在管理员完成环境建设并开放后才能登录。入口不可用时联系管理员，不要改用生产入口进行测试。

预发布使用脱敏验证数据，Dev 使用虚构开发数据。登录页标题和登录后的页面显示对应环境标识，填写账号前先核对环境。预发布账号以 `@staging` 结尾，Dev 账号以 `@dev` 结尾，不能跨环境登录。

首次登录使用临时密码时，先进入账号与安全页面修改密码，再重新登录。修改密码会退出已有会话。Dev 用于架构开发和功能验收，预发布用于候选版本回归和压力测试；两者均不处理真实生产任务。

如果入口提示 `environment_static_bundle_invalid`，表示该环境的页面资源与服务版本不配套。请联系环境管理员重新部署配套版本后刷新当前入口；不要切换到生产入口继续测试。
