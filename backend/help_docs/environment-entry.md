# 生产、预发布与 Dev 环境入口

正式业务使用普通平台账号登录。网页和桌面客户端都不提供“进入预发布环境”按钮：在普通登录页使用完整用户名以 `@staging` 结尾的预发布账号时，系统会自动选择固定的预发布 API，不要求先打开 `/staging/`。Dev 入口仍是 `/dev/`。预发布或 Dev 环境只有在管理员完成环境建设并开放后才能登录；环境不可用时联系管理员，不要改用生产账号进行测试。

预发布使用脱敏验证数据，Dev 使用虚构开发数据。登录成功后页面会显示对应环境标识。预发布账号必须严格以 `@staging` 结尾，网页和桌面客户端都只连接固定 `/staging/api` 并核对服务端环境身份；连接失败或身份不匹配时会停止登录，不会回退到生产 API。显式打开 `/staging/` 时也只能使用预发布账号。Dev 账号以 `@dev` 结尾，必须从 `/dev/` 入口登录，所有环境账号均不能跨环境使用。

首次登录使用临时密码时，先进入账号与安全页面修改密码，再重新登录。修改密码会退出已有会话。Dev 用于架构开发和功能验收，预发布用于候选版本回归和压力测试；两者均不处理真实生产任务。

如果入口提示 `environment_static_bundle_invalid`，表示该环境的页面资源与服务版本不配套。请联系环境管理员重新部署配套版本后刷新当前入口；不要切换到生产入口继续测试。
