# 滨湖智慧平台文档索引

本目录保存可在家里和单位电脑之间通过 Git 同步的项目知识。所有共享文档都不得包含真实密码、令牌、生产主机地址或个人电脑绝对路径。

## 权威性顺序

1. 当前源码、配置、数据库结构和实时只读验证结果。
2. 本索引指向的现行文档。
3. `archive/` 中的历史材料，仅用于追溯。
4. 本机私密文件，不得作为其他电脑上的默认事实。

## 现行文档

| 文档 | 用途 | 何时阅读 |
|---|---|---|
| [共享协作规则](../AGENTS.md) | 证据协议、稳定约束、安全边界与最低验证 | 每个任务开始时 |
| [架构说明](architecture.md) | 系统数据流、数据库层次、解析器、日报和路由边界 | 修改业务逻辑或接口前 |
| [运维与开发手册](operations.md) | 本地开发、双地点 Git、备份、恢复和部署门禁 | 开发交接或运维前 |
| [风险登记](known-risks.md) | 已验证但尚未修复的问题、证据与第二阶段方向 | 部署、安全或故障任务前 |

## 历史材料

历史部署与迁移计划已移动到 [archive/plans](archive/plans/README.md)。这些文件可能描述旧路径、旧端口和已经失效的操作顺序，禁止直接复制执行。

## 维护原则

- 稳定规则写入 `AGENTS.md`，详细事实写入对应文档，历史过程进入归档。
- 源码能够直接表达的事实优先链接源码入口，不复制行号或大段接口清单。
- 运行状态必须注明验证日期、方法和限制。
- 风险只有在代码、配置和运行状态均完成验证后才能关闭。
- 文档变更提交前执行链接检查、敏感信息扫描和 `git diff --check`。
