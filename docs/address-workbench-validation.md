## 实现范围

- 桌面任务小区字段、手机卡片、独立详情统一为可点击状态标签，删除候选大面板及废弃样式。
- 精确任务链接可打开自动匹配/已确认任务；工作台按稳定地址顺序提供队列、同社区全量搜索选项、明确提交、下一条、最近处理和返回原工作位置。
- `manual_unmatched` 为人工负结论；`review_required` 为输入变化后的待复核，前端显示“待确认”，后台后续重算仍保留复核门禁。

## 用户视角复审及修正

| 发现的问题 | 修正与复验 |
| --- | --- |
| 更新排序会让刚处理任务移位，下一条可能跳错 | 改稳定地址排序，保存前保留下一任务定位；23 条连续处理通过 |
| 回看按钮的返回位置被新目标覆盖 | 捕获原任务定位，复验第 2 条→第 1 条→第 2 条 |
| 队列/直达按钮文案与实际动作容易混淆 | 显式队列模式；图标按钮增加可访问名称，浏览器按名称点击并校验结果 |
| 搜索后已选小区名称丢失 | 独立保存所选名称，切任务时清空，版本冲突保留选择 |
| 小窗口筛选和事实区过高 | 单行工具栏、压缩事实区；窄屏核对隐藏筛选并提供返回队列 |
| 409 若直接重载会清空选择 | 读取最新详情保留选择，阻止自动再次提交 |
| 浏览器返回事件晚于路由处理，草稿保护不生效 | 在 Router 挂载前注册 POP 门禁，完整外壳取消返回测试通过 |
| 返回按钮确认放弃后，POP 门禁可能再次询问 | 明确放弃后同步清除草稿标记；浏览器验证只询问一次并返回原位置，取消返回仍保留草稿 |
| 只改变 CSS 并不代表真实深色组件 | 使用真实主题算法与系统主题设置重新截图检查 |
