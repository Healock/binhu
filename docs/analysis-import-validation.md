# 导入研判结果 UX 验收记录

日期：2026-09-08。基线：`71c81fd2`（main）。分支：`codex/ux/import-review-result`。本次保持 open PR，不合并、不部署、不打标签。

## 问题与修复

原流程只调用 `message.warning("已导入 0 条，1 条需要处理")`，随后刷新列表。用户看不到哪一行有问题、为什么失败，也没有修正后重新导入的入口，因此导入结果在提示后中断。

现在导入结果会持久显示在研判列表下方：

- 显示成功数量和需要处理数量；
- 逐行显示 XLSX 行号与安全错误原因；
- 明确说明成功行不会重复写入，问题行可修正后重试；
- 提供“重新导入修正后的文件”入口；
- 全部成功时显示列表刷新和待研判数量变化提示；
- 可关闭结果面板，但不会阻断继续筛选和处理。

错误原因来自后端已有安全分类，不在普通提示中显示地址、身份证号、手机号或原始正文。
