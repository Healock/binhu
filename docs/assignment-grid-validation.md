# 分配工作台多列布局修复验收

日期：2026-09-08。基线：`71c81fd2`（main）。独立分支：`codex/ux/assignment-grid`。本次仅提交 open PR，不合并、不部署、不打标签；与确认地址 PR #519、dev 和原工作区临时文件独立。

## 原因与修复

- 已在真实 Ant Design Modal 中复现 main 的首次打开单列：父组件的 `open` effect 早于 portal 内滚动容器挂载，ref 为空时返回，列数一直保持 1。
- 用节点回调记录实际滚动容器，节点挂载后通过 `useResponsiveLayout` 订阅尺寸，按原有 250px 卡片与 10px 间距计算完整虚拟行。
- 统一尺寸读取改用 `clientWidth`，排除滚动条与弹窗进场缩放动画影响；不改变 compact/standard/wide 分档规则。
- 虚拟行增加 10px 行间距，长地址仍完整换行并按实际高度测量。
- 视觉复审修正窄屏竖排继承桌面 `flex-basis` 导致的大块空白；空通知区不占位。
- 弹窗使用 Ant Design 6 的 `container` 样式，内容高度随窗口，任务区独立滚动，底部分配按钮保持可达。
- 拖选结束后键盘 Space 不再被鼠标点击抑制标记吞掉；鼠标拖选产生的点击仍抑制一次。
