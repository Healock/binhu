# 外部数据获取后台任务

从 0.25.4 起，可能访问外部平台的手动获取入口统一返回 `202 Accepted` 和运行 ID，浏览器不再等待外部请求完成。页面通过 `GET /api/external-acquisition/runs/{id}` 被动轮询状态；任务会在页面刷新或离开后继续执行。

当前纳入的入口：

- 走访明细、 新星级评分管理：只读预览任务，完成后进入原有“待确认”流程。
- 平安码、管家码：获取并生成每日快照任务。
- 调照片名单：只读预览和立即同步任务。

运行记录只保存来源、阶段、计数、结果摘要和安全错误码，不保存姓名、身份证号、地址或完整外部响应。服务重启时未完成任务会标记为 `interrupted`，不会伪装成仍在运行。

已有的责任告知书读取、下发任务发布、全民防反馈扫描和定时调照片同步任务继续使用各自的专用运行表；本次不重复创建第二套任务。
