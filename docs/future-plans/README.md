# Future plans 目录说明

`docs/future-plans/` 保存已经确定方向、但尚未进入实施的长期项目。`docs/future-plans.md` 是唯一总目录；本目录中的文件负责记录单个项目的范围、约束、验收和后续状态。

## 维护规则

- 每个项目独立一个 Markdown 文件，文件名使用稳定英文 slug。
- 项目状态变化时先更新项目文件，再更新总目录。
- 计划文档不能替代代码、测试、部署或验收证据；描述已完成事项时必须链接对应提交、PR、测试或台账。
- 历史归档不回写。当前计划不得包含凭据、完整地址、身份证号、手机号或其他敏感业务正文。
- 新项目开始前重新核对 `AGENTS.md`、实际代码、环境身份、数据边界和当前 PR 状态。
- 当前环境统一称为生产环境、预发布环境和 Dev 环境；历史证据中的“影子环境”称呼保留。
