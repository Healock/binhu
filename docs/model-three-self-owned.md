# 辖区资产：自购自住人员资料

## 数据类别

“自购自住明细”不是新的流口业务表，也不只是为了补齐模型三结果而维护的临时名单。它属于**辖区资产资料**，记录辖区内自购自住房屋的居住人员，后续可以作为房屋档案、人员档案和相关核查工作的基础资料。

当前首版先在数据上传中心导入，并将资料与模型三任务进行安全匹配。匹配更新是资产资料进入平台后的一个应用场景，不改变这类资料的业务归属。

## 处理规则

- 管理员在数据上传中心导入 ZIP；ZIP 内可包含多个 XLSX。
- XLSX 必须包含“居民证号”（兼容“身份证号/身份证号码”）列。
- 身份证先做格式校验，再按 HMAC 去重；平台不保存身份证明文、姓名、电话、地址或原始工作簿。
- 当前首版只把资料匹配到 `疑似未注销模型三` 任务；这不是对资产资料类别的限制，后续可扩展到辖区房屋和人员档案。
- 当前“核查结果”为空或为“无法核实”时，平台填入“近期返吴”。
- 已有其他核查结果，或存在待处理的平台本地编辑时，保留原结果并计入“保留原结果”。
- 该功能只修改滨湖平台，不调用全民防登记或其他外部写入接口。

## 批次与安全边界

每次导入保存文件哈希、规则版本、数量摘要、导入人和时间；最近批次接口只返回安全摘要，不返回内部账号 ID 或原始名单内容。相同文件哈希不会重复导入。

数据库表名 `_qmf_self_owned_*` 和接口路径 `/api/qmf-source/self-owned/*` 是首版兼容命名，不代表这类资料属于全民防或模型三来源。

当前规则版本为 `self-owned-v1`。后续若姓名、小区或其他辅助信息加入匹配，应升级规则版本并补充脱敏 fixture，不能直接改变历史批次含义。
