# 人员标签

“人员标签”用于维护需要长期识别和筛选的特殊人员。目前平台预置四个核心分类：

- 通勤人员
- 五失人员
- 重点人员
- 精障人员

内部数据库表、权限代码和接口路径仍保持原有兼容名称，页面、导航、权限目录和操作记录统一使用“人员标签”。同一人员按身份证号唯一归档；同一分类只保留一条当前有效标签，重复来源行作为来源记录保留，不重复创建人员或标签。

## 通勤人员名单导入

超级管理员可以在“人员标签”页面选择多个 `.xls` 或 `.xlsx` 文件，先预览再确认。预览只返回数量、分类和安全状态，不返回名单正文；确认前发现身份证为空、身份证格式或校验位异常、姓名冲突、手机号冲突、已有档案停用或姓名不一致时会阻断导入。

导入支持有表头名单和“姓名 + 身份证号”两列的无表头名单。身份证会清理首尾空格、全角空格、末位 `x/X` 和明确的 Excel `.0` 尾缀，并执行出生日期与校验位检查；不会猜测异常号码。来源手机号只会幂等补充到对应人员档案。

名单通常只到派出所级别，平台不会猜测社区归属。确认导入后，现有在线任务会在下一次正常同步时补齐人员标签快照；导入本身不会修改腾讯在线表或制造测试任务。

## 本地基准统计

用于本地验证的三份通勤名单合计 1,528 条来源行，按身份证去重后为 1,291 人；来源行重复不会重复建档。统计过程中未发现身份证、姓名或手机号冲突。正式生产导入仍必须由超级管理员在部署后的预览页面再次核对，并在确认前完成 `RegistryData` 备份。
