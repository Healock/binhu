# 流口指令核查 2026-09-14 当前任务清理

## 范围

本次只处理 Production 中页面“流口指令核查”对应的 `全链条` 当前任务，且业务日期必须严格解析为 `2026-09-14`。9 月 14 日以前的业务数据、日报、账号、审计、附件和其他业务类型不在清理范围内。

## 受控流程

生产固定网关只接受以下阶段，并为每次运行创建不可覆盖的证据目录：

```text
measure → backup-check → prepare → apply → verify
```

`measure` 生成目标行键（仅稳定键摘要）、来源 ID 和各关联表数量；`backup-check` 要求最近的八库备份存在、gzip 可读、清单完整且 SHA-256 一致；`prepare` 固化目标清单和备份 ID；`apply` 在 MySQL 命名锁和单事务内把业务行追加到 `OnlineDataArchive.t_fullchain_archive`，再归档来源登记、取消待处理投影/队列、标记流程和任务图来源缺失，最后移除当前业务行；`verify` 确认目标日期当前数量为零、9 月 14 日以前数量与测量值一致、归档数量增加且服务健康。

维护入口固定为：

```text
current-flow-cleanup <phase> <run_id> 2026-09-14
```

网关拒绝其他日期、其他业务类型、非法运行编号和未按顺序准备的 `apply`。失败时保留失败证据并回滚事务，不覆盖上一份可用副本。
