# 模型三自动归档修复与当前任务清理（2026-09-08）

用户明确授权修复自动归档，并要求生产模型三当前任务数量归零。本次不清理其他业务、照片工单或既有归档。

## 根因与代码修复

模型三自动归档写入归档表并移除当前业务、来源和投影，却未关闭 `_local_source_records`，导致旧登记仍为 active。

- 在原归档事务内，按模型三业务类型和待归档业务键，将 active 本地来源置为 archived、填写归档时间并递增 revision。已经 superseded/archived 的记录保持不变。
- 归档插入取消 `IGNORE`，写入失败必须回滚，不能忽略异常后删除当前任务。
- 移除当前来源只匹配 archived_at 为空的记录，保留历史来源。
- 保持既有到期、反馈一致和已完成条件；不增加任何外部请求。
