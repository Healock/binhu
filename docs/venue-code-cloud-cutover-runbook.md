版本：2026-09-15

本手册用于候选环境验收和正式切换。生产开关、二维码轮换、数据库写入和 Nginx 路由变更必须在前置核对完成并获得维护窗口批准后执行。云端不连接滨湖业务数据库，`RegistryData` 仍是场所和登记记录的唯一正式来源。

## 一、只读前置核对

使用登记的持久 SSH MCP 候选目标，复用同一会话完成以下检查；不得把候选地址、端口、用户或密钥通过命令参数传入。MCP 不可用时，只允许使用一次受控只读连接并记录原因。

检查项目：

- 域名解析、HTTPS 证书有效期和现有续签计时器；
- mTLS CA、客户端证书、Ed25519 公钥/私钥和 RSA 公钥/私钥的存在、类型、权限和 key id；
- `/srv/binhu-venue`、`/etc/binhu-venue`、独立 Compose 项目和专用 Docker 网络；
- Receiver、Ingress、MySQL 健康状态和不可变镜像提交号；
- Receiver `/health/ready`、Nginx `/venue/` 路由和既有 `/updates/` 路由；
- 日志脱敏、照片目录权限、数据库目录权限和磁盘空间；
- `pending`、`uncertain`、过期和失败数量；
- 回滚镜像、Nginx 备份和部署台账；
- 试点场所、三批清单、打印负责人、替换顺序和旧码回收方式。

只记录状态、数量、时间、摘要和哈希，不记录密钥正文、证书私钥、令牌、登记正文、照片或完整地址。

## 二、备份和台账

生产开关变化前备份：

1. 滨湖 `RegistryData`；
2. 云端场所码 MySQL；
3. 云端照片目录；
4. 当前和上一 Receiver 镜像引用；
5. Nginx 配置和 Compose 环境快照；
6. 场所 token/config revision 对账结果。

每份备份记录 UTC 时间、路径、字节数、SHA-256、数据范围和恢复引用。建议使用 `deploy/venue-cloud/deployment-ledger.example.json` 作为字段模板；真实台账保存在服务器受保护目录，不提交 Git。

## 三、云端配置同步与单场所闭环

先执行只读 measure，确认启用场所数量和待轮换数量，再在批准的维护窗口执行 apply，最后执行 verify。新 token 输出文件权限必须是 `0600`，在单场所验收前不得打印或发放。

单场所闭环必须使用虚构登记资料和测试照片完成：

1. 本地场所配置同步到云端；
2. 新二维码打开云端页面并发放一次性 token；
3. 提交后云端加密保存；
4. 滨湖主动拉取、验签、解密并在本地事务写入一条记录；
5. ACK 后云端状态为 `accepted`；
6. 重复 `submission_id` 不产生第二条本地记录；
7. mTLS、伪造签名、过期 nonce、损坏密文、租约过期、ACK 不完整和响应丢失进入明确失败或 `uncertain`，不得自动重放。

闭环任一项失败，停止切换，不进入第一批。

## 四、三批切换和入口关闭

第一批为 5–10 个场所，观察 1–2 小时；第二批为 20–30 个场所，观察 2–4 小时；第三批为剩余全部场所。每批记录开始/结束时间、场所数量、同步结果、拉取结果、accepted/rejected/uncertain/expired 数量和回滚状态。

全部批次通过后，确认主动拉取稳定运行，再关闭 `VENUE_LOCAL_PUBLIC_ENTRY_ENABLED`。随后必须验证：新二维码继续打开云端页面，旧二维码返回 HTTP 410，虚构登记在本地只落一条记录。

## 五、回滚和 72 小时观察

出现生产异常、数据不一致、重复落库、版本漂移、签名/mTLS/解密失败、`uncertain` 无法解释增长、日志泄露正文或云端组件不健康时，立即停止后续批次：关闭主动拉取、保留云端队列、回退 Receiver 镜像或配置，并以 `cloud_submission_id` 对账。数据库不自动恢复，本地入口是否恢复必须单独确认。

入口关闭后连续观察 72 小时，至少检查 Receiver/Ingress/MySQL、pending/uncertain/expired、租约和 ACK、重复登记、场所版本漂移、日志脱敏、证书续签、磁盘和照片清理。观察期内保留回滚材料。

## 禁止事项

- 不恢复腾讯表、腾讯 OAuth、腾讯写回或腾讯物理行号；
- 不让云端连接滨湖业务数据库；
- 不把真实登记资料用于候选测试；
- 不在未完成前置核对时启用开关、打印新码、替换旧码或部署正式链路；
- 不自动恢复数据库、不自动重放 `uncertain`、不删除云端队列作为“清理”。
