# 场所码接口清单

| 方法 | 路径 | 权限 | 用途 |
|---|---|---|---|
| GET | `/api/venue-codes` | `venue.view` | 场所目录 |
| POST | `/api/venue-codes` | `venue.manage` | 创建场所并生成随机令牌 |
| PUT | `/api/venue-codes/{id}` | `venue.manage` | 编辑或停用场所 |
| POST | `/api/venue-codes/{id}/rotate-token` | `venue.manage` | 撤销旧令牌并轮换新令牌 |
| GET | `/api/venue-codes/{id}/qrcode` | `venue.view` | 获取扫码地址/二维码 PNG |
| GET | `/api/venue-visits` | `venue.view` | 分页查询登记记录 |
| GET | `/api/venue-visits/export` | `venue.export` | 受审计保护的 XLSX 导出 |
| GET | `/api/public/venue-codes/{token}` | 匿名 | 获取公开登记页的短时表单令牌 |
| POST | `/api/public/venue-visits` | 匿名 | 一次 multipart 请求提交文字和照片 |
| GET | `/api/venue-visits/{id}/photo` | `venue.view` | 受保护查看照片 |

公开接口不接受任意路径或单独照片上传；停用场所、过期或已消费表单令牌、空或无效身份/手机号/地址/照片和超过限流均拒绝。
