# 场所码核心功能整合（v0.27.x 功能分支）

本功能从 `shop-collector` 提取业务概念，在滨湖平台中独立实现，不复制其 PHP 单体、店长码入口或外部政务平台调用。

## 范围

- 后台创建、编辑、停用场所并轮换随机二维码令牌；
- 手机扫码填写姓名、公民身份号码、手机号、地址和照片；
- 后台按场所查看登记记录并按权限导出 XLSX；
- 登记记录及照片默认保留 90 天，后台清理任务到期软删除并清理文件。

场所码不读取、修改或关联流口指令核查，也不提供批量登记、OCR、店长码或外部平台写入。

## 接口

后台接口位于 `/api/venue-codes`、`/api/venue-visits`，分别受 `venue.view`、`venue.manage`、`venue.export` 权限保护。公开入口为 `/venue/{token}` 和 `POST /api/public/venue-visits`，写入必须同时携带短时签名表单令牌和 multipart 照片。

二维码令牌使用随机高熵值，数据库只保存 HMAC 和加密值。登记的姓名、身份证号、手机号、地址使用应用 Fernet 密钥加密；身份和手机号另存 HMAC 供精确检索。普通日志和审计不记录敏感正文。

## 数据表

场所表、登记表和照片元数据表均位于 `RegistryData`：`_venue_codes`、`_venue_visits`、`_venue_visit_photos`。照片文件存于受控 `VENUE_PHOTO_DIR`，不挂载公开静态目录。

## 已知限制

当前二维码接口返回扫码地址和令牌元数据；前端可直接复制地址。生产环境如需图片二维码，应在部署依赖中提供二维码生成器并在该接口增加 PNG/SVG 输出。所有真实数据验收应使用虚构 fixture 或受控环境完成。
