# 诊断问题功能

诊断功能面向运维人员，普通用户无需点击按钮或提供任务 ID。业务请求发生服务端异常时，平台异步记录脱敏现场，管理员可在运维中心按用户姓名查询最近记录，并对选中的记录执行深度诊断。

## 数据与安全

- 诊断任务和报告保存在 `PlatformData`，保留 90 天。
- 只保存页面路径、错误码、有限的请求标识摘要和脱敏错误摘要。
- 禁止写入身份证号、手机号、姓名、地址、Cookie、Authorization、密码、令牌或外部原始响应。
- 诊断写入失败只记录应用日志，不影响原业务请求。

## 运维

首次部署只发布代码。生产执行 DDL 前应备份 `PlatformData`：

```text
python -m migrations.diagnostics measure
python -m migrations.diagnostics migrate
python -m migrations.diagnostics migrate --apply
python -m migrations.diagnostics verify
```

`diagnostic-worker` 独立运行，Redis Stream 用于快速唤醒，MySQL `queued` 状态是可靠兜底。Redis 不可用时，Worker 仍会轮询执行已排队任务。
