# v0.25.21 更新日志

1. 页面间距与布局可靠性
- 修复房屋档案、在线查询和运维中心详情区域中带边框组件贴在一起的问题，让标题、描述、面板、表格和操作区之间保持稳定间距。
- 统一移动端卡片列表、报表、数据预览和下发面板的分组间距，避免条件渲染或组件样式覆盖后出现布局塌陷。
- 同步补充浅色、深色、桌面和窄屏布局回归检查，并把“贴边”问题的扫描范围固化到开发规范中。

2. 版本更新说明更清晰
- 发布流程支持由 Codex 按版本内已合并 PR 汇总主题化更新日志，Release 和桌面端“版本已更新”弹窗使用同一份内容。
- 更新日志加载增加兼容回退和结构化展示，避免日志格式错乱或随桌面资源路径变化而加载失败。
- 保留 PR 编号技术追溯，但不再把多个 PR 的原文直接堆叠给使用者。
