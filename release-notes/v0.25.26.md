# v0.25.26 更新日志

1. 后台任务问题明细与安全重试
- 管理员和超级管理员现在可以在后台任务队列中展开查看冲突、暂停和等待重试的具体记录，并看到脱敏任务引用、错误类型、原因分析与建议处理方式。
- 调照片腾讯写回在确认属于安全重试范围时，可直接从任务队列重新加入处理；存在来源冲突或写错风险的任务继续禁止盲目重试。
- 问题明细按需读取，不会把姓名、身份证号、手机号、地址、业务正文或外部系统响应带入队列页面和日志。

2. 重要公告登录提醒
- 重要且尚未阅读的公告会在登录后使用全屏弹窗提醒，确认阅读成功后不再重复弹出；普通公告和个人通知保持原有消息中心展示方式。
- 公告弹窗与“版本已更新”弹窗统一使用同一个样式组件，视觉、深浅色和手机端布局保持一致。
- 版本更新说明优先展示，关闭后再依次展示未读重要公告，避免多个全屏弹窗互相遮挡。

3. 侧边栏与运维页面布局修复
- 侧边栏继续支持滚动，但隐藏可见滚动条，减少窄屏界面的视觉干扰。
- 修复运维中心腾讯额度提示、统计区和表格之间贴边的问题，统一由父级间距控制连续业务区块。
