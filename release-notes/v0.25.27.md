# 滨湖智慧平台 v0.25.27 更新日志

本次版本重点修复桌面端高密度表格的小控件显示问题。

## 表格展开按钮对齐修复

- 修复辖区档案等可展开表格中，展开按钮外框已经变方但内部加号仍然偏移、长度不一致的问题。
- 加号的横线和竖线现在使用同一个中心点、同一长度和同一厚度，展开与收起状态只改变旋转，不再依赖组件库两套不同的内缩计算。
- 保持浅色、深色、紧凑窗口和 Windows 缩放下的方形点击区域，避免再次出现“十字架”或长条形控件。

## 技术追溯

- 本版本由表格展开按钮对齐修复提交生成。
- 未修改后端接口、数据库、业务数据、权限或外部平台写入逻辑。

## 更新说明

桌面客户端优先使用更新服务器提供的增量包；增量包不可用时自动回退到全量包。
