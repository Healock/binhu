# 滨湖客户端 0.26.3

## Windows 客户端

- 修复 Windows 7 下载更新后，VxKex 在启动新版程序时提示“CreateProcess 失败：拒绝访问”的问题。更新重启时会等待 Velopack 完全退出，再启动新版 Electron 客户端。
- Windows 7 增加增量包下载进度补偿和更新日志，避免下载过程长时间显示 0%。
- Windows 10/11 恢复文件拖放上传，并完善 WebView2 首次安装引导和安装器信息。
- 优化 1024×640 等紧凑窗口下的任务表格、操作按钮和更新提示布局。

## Android 客户端

- 纳入 Android Tauri 客户端工程，支持本地前端资源、全面屏安全区域和系统拨号。
- 增加 Android 完整 APK 自更新、断点续传、文件及签名校验、强制升级策略和系统安装授权流程。
- 为旧版 Android System WebView 增加必要的 JavaScript 兼容补丁。

## 发布与运维

- 扩展统一客户端发布流水线和更新服务器校验能力，支持 Windows 7、Windows 10/11 与 Android ARM64 三个平台。
- 更新包继续通过受限 SSH 网关发布，并保留版本、提交、文件长度和 SHA-256 校验。
