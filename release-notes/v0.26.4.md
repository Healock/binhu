# 0.26.4 更新日志

1. 全链条归档更可靠
- 腾讯表正在被其他回写任务占用时，归档会先等待并在锁释放后继续，不再因为短暂锁竞争直接失败。
- 服务重启或临时竞争后，归档任务可以接回队列；已经成功处理的条目不会重复删除或重复归档。
- 持续无法取得锁时会显示明确的等待或失败原因，方便后续处理。

2. 任务字段与业务反馈更清晰
- 疑似返苏的“无需登记”和“移交”反馈可以分别记录原因或移交社区。
- 出租房屋核查支持填写入住方式；苏州涉警和交通涉警支持网格员填写备注。
- 非全链条任务不再显示不适用的来源和照片操作，移动端详情编辑更紧凑、更易读。

3. 在线人数刷新更及时
- 页面恢复、窗口重新聚焦或网络恢复后会立即刷新在线人数。
- 临时请求失败时保留最近一次成功结果，避免在线名单突然清空。
- 打开在线详情时会同步刷新名单，成功后恢复正常周期更新。

4. 走访汇总导出更直观
- 社区汇总导出表中，三项效率指标的最低三个有效数值会分别标黄，帮助快速发现需要关注的社区。
- 空值、非数值和合计行不会参与最低值标记，少于三个有效社区时按实际数量显示。

5. Windows 客户端导出修复
- Electron 和 Tauri 客户端导出 XLSX、PDF、ZIP 等文件时改用可靠的本地保存方式，文件可以正常落到系统下载目录。
- 网页端仍保留原有下载方式，桌面端和网页端的导出权限与数据内容不变。

6. 发布与协作流程改进
- 补充远程 PR、CI、主线检查和发布状态的核对规则，减少“本地通过但远程失败”的情况。
