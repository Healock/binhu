# 0.26.5 更新日志

1. Windows 桌面增量更新基线隔离
- 修复 Win7 和 Win10/11 构建任务共用上一版本 Full 包目录、可能误选其他平台基线的问题。
- 每个平台现在只读取自己的上一版本 Full 包，并在构建前校验文件名、Nuspec PackageId 和版本号。
- 更新网关新增跨平台 nupkg、PackageId 和清单引用校验，发现平台污染会拒绝发布。

2. 发布流程安全规范
- 将桌面发布中的平台隔离、构建前后校验和污染版本处置规则写入 `AGENTS.md`。
- 已发布版本不通过覆盖清单或重写 Delta 修复；发现问题时通过更高修订版本重新生成 Full/Delta。

## 技术追溯

- #377 修复 Windows 桌面发布基线包串用及更新服务器平台污染校验。

## 验收提示

- 检查 Win7、Win10/11 发布日志，确认各自使用对应平台的上一版本 Full 包。
- 验证错误平台 PackageId、错误版本或跨平台清单引用会在发布前失败。
- 使用上一版本客户端分别验证两端增量更新和全量回退。
