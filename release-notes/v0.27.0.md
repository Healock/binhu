# 滨湖桌面客户端 v0.27.0 更新日志

本次版本由提交 `18881702e278` 生成。

更新范围：v0.26.6 → v0.27.0。

## 更新内容

### 1. 居住证平台首次登记状态
- 增加首次登记任务的只读核对能力，并在任务卡片、表格和详情中统一展示安全状态。
- 增加超级管理员配置、验证码登录、手动重查和后台状态记录；外部平台仅执行授权的只读查询。

### 2. 账号安全操作记录
- 补充修改密码、管理员重置密码、设备下线和头像更换等安全操作记录。
- 操作记录仅保存安全摘要，不记录密码、会话值或头像正文。

### 3. 流口任务表格稳定性
- 修复移动任务表格编辑器上下行错位，改善小屏下的编辑体验。

### 4. 验收提示
- 使用授权测试数据检查首次登记、已有登记和查询异常三种状态的显示差异。
- 在运维中心核对账号安全操作记录，确认详情不包含敏感凭据。
- 在移动任务页面编辑多行数据，确认控件与保存结果保持同一行。

## 技术追溯

本次版本没有检测到新的合并 PR。

## 更新说明

桌面客户端优先使用更新服务器提供的增量包；增量包不可用时自动回退到全量包。
