# 滨湖桌面客户端 v0.27.14 更新日志

本次版本优化流口指令核查的筛选、分配恢复和业务数据导出，并补齐历史手机号字段兼容，方便小屏验收和业务人员查看导出结果。

版本号已同步到服务端、前端、Windows 客户端和 Android 客户端。

## 更新内容

1. 流口指令核查筛选更清晰

- 页面默认筛选调整为“全部”。
- 顶部状态顺序统一为：全部、普通待处理、等待研判、已研判、来源异常、已完成。
- 重置筛选和切换业务后也会回到“全部”，减少误以为数据丢失的情况。

2. 已分配数据可安全撤销

- 增加“撤销本社区已分配”功能，操作前会二次确认。
- 只撤销未完成任务的核查人分配，不删除已有核查结果、研判、反馈和历史记录。
- 来源异常、重复来源或并发变化的数据会安全跳过，并返回逐条原因。

3. 业务数据导出更适合实际使用

- 普通业务导出聚焦姓名、身份证号、手机号、地址、社区、核查人、状态、研判和反馈等主要信息。
- 不再导出任务标识、来源哈希、流程版本等内部技术字段。
- 兼容“电话号码”“手机号码”“联系号码”“手机号”等历史字段，避免手机号列有表头但没有数据。
- 待研判导出仍保留回导所需的必要标识，保证基础管控研判流程不受影响。

4. 本地数据源运行路径更快

- 本地数据源模式下不再执行历史腾讯表删除后对账流程。
- 正常任务导出、筛选和处理不再等待腾讯表读写。

## 技术追溯

- #448：流口任务筛选、分配撤销、本地业务导出与手机号字段兼容。

## 更新说明

桌面客户端优先使用更新服务器提供的增量包；增量包不可用时自动回退到全量包。更新并重启后，首次进入已登录业务页面会显示本版本更新内容。
