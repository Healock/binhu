# 滨湖桌面客户端 v0.27.16 更新日志

本次版本恢复本地日报自动更新，修复居住证会话失效和自购自住名单上传问题，并上线首版“小区地址匹配与人工确认”能力。

版本号已同步到服务端、前端、Windows 客户端和 Android 客户端。

## 更新内容

1. 地址匹配与小区筛选

- 根据本地小区地址库、标准名称、别名和地址片段，为房屋档案及指令任务生成小区匹配建议。
- 辖区档案、指令核查和分配工作台支持按社区、小区及匹配状态筛选。
- 系统建议必须由有权人员人工确认后，才允许单人分配或平均分配；未匹配、多候选、地址冲突和来源异常任务不会被自动分配。
- 原始地址、原始社区和已经人工确认的结果不会被规则重跑覆盖。
- 首版只使用本地规则，不启用 Elasticsearch 或 MGeo，也不会自动改变任务归属。

2. 本地日报恢复自动更新

- 后端启动后会立即生成当天在线数据快照、分项汇总和总汇总，之后每 10 分钟自动刷新。
- 多个后端实例通过互斥保护避免重复生成；任一分项失败时不会发布不完整的总汇总。
- 日报完全读取本地业务数据，不恢复腾讯表同步。

3. 居住证查询会话自动恢复

- 居住证平台将会话失效包装为 HTTP 500 时，系统现在能够识别认证失效、重新登录并安全重试一次。
- 普通网络错误或普通 HTTP 500 不会被误判为登录失效，也不会无限重试。
- 后台任务增加安全错误分类汇总，便于定位受影响社区，不记录上游正文或人员敏感信息。

4. 自购自住名单 ZIP 上传修复

- 修复较大的自购自住名单 ZIP 在生产入口被 HTTP 413 拦截的问题。
- 1–100MB 的合法 ZIP 可正常进入原有导入校验流程；超过 100MB 时页面会提前提示文件过大。
- 网关拒绝或上传超时时显示明确原因，不再只提示笼统的“导入失败”。

## 更新说明

桌面客户端优先使用更新服务器提供的增量包；增量包不可用时自动回退到全量包。更新并重启后，首次进入已登录业务页面会显示本版本更新内容。

地址匹配首版只生成建议。上线后需先完成数据库备份和房屋匹配维护核验，再由有权限的管理员确认小区归属；系统不会擅自覆盖原始地址、原始社区或人工确认结果。
