# 滨湖智慧平台 v0.27.3 更新日志

## 更新内容

1. 快捷下发覆盖更多业务类型

- 快捷下发现在支持全链条、出租房屋核查、疑似返苏、所内涉警、苏州涉警、交通涉警和寄递业。
- 表单会根据目标业务类型自动显示对应字段，并继续先进入下发工作台审核，不会绕过发布流程直接写入外部表格。

2. 流口任务详情补充居住证登记资料

- 对已确认存在居住证登记的任务，详情中可以按需查看登记照片、登记住址、出生日期、户籍地址、民族和注销状态。
- 资料只在当前详情请求中读取和展示，不写入任务缓存、普通日志或审计记录；查询失败时只影响资料区块，不影响任务详情其他内容。

3. 组员可在编辑时领取未分配任务

- 组员编辑尚未分配核查人的任务时，可以确认领取并同时保存本次核查内容。
- 领取人由服务端根据当前登录账号确定，并通过并发校验避免两名组员互相覆盖。
