# 滨湖智慧平台 v0.27.5 更新日志

## 更新内容

1. 无法核实两级研判与归档闭环

- 全链条、出租房屋核查、寄递业、疑似返苏、苏州涉警和交通涉警统一增加“初步研判—深度研判—最终无法核实”处理链路。
- 初步研判成功后固定延时 2 个完整自然日，深度研判成功后固定延时 1 个完整自然日；延时到期后由后台安全推进，期间一旦核实成功，网格员可以立即修改为正式核查结果并结束流程。
- 最终无法核实的数据在各业务任务页分别预览和导出。系统逐条复核来源、版本和内容后，删除腾讯表对应整行并写入历史归档，导出文件可供后续重新下载。
- 来源缺失、重复、版本变化或写回冲突时自动暂停，不使用旧行号或旧内容覆盖当前数据。

2. 流口任务紧凑布局与行内待登记

- 姓名、身份证号、手机号和原地址在不同窗口宽度下按横向、2×2、4×1 逐级调整，较小分辨率下仍保持核心人员信息可见。
- 用户可以直接在任务表格行内选择“待登记”并关联辖区房屋，无需先进入详情页。
- 普通状态统一显示“核查补充信息”，选择待登记后切换为“现住址”；房屋候选项只显示标准地址，不再重复添加社区名。
- 移除多余的旧“移交”结果选项，普通用户仍不能直接选择“已登记”。

3. 场所码登记

- 新增场所目录、二维码生成与轮换、手机匿名扫码登记、后台记录查询、受控照片查看和 XLSX 导出。
- 场所码权限默认仅授予超级管理员，后台操作继续执行独立权限校验；敏感字段按受控方式存储，普通日志和审计不记录人员正文。
- 登记资料按 90 天规则清理，并与流口任务、腾讯同步和其他业务流程保持独立。
- 首次使用前需要确认公开 HTTPS 访问地址、二维码路径和私有照片目录权限；本版本未使用真实人员或真实照片执行自动验收。

4. Windows 客户端快捷方式

- Win7 和 Win10/11 的桌面及开始菜单快捷方式统一显示为“滨湖智慧平台”，并使用正式应用图标。
- 客户端更新后会重新指向当前版本目录，避免快捷方式继续打开旧版本程序。
- 新快捷方式创建成功后会清理旧的 `BinhuDesktop` 快捷方式；若系统目录不可写，则保留旧入口，避免用户失去启动方式。

## 验收提示

- 两级研判及腾讯整行删除涉及外部数据写入。上线后先核对阶段数量、来源异常和后台任务，再由授权人员使用少量可控数据验收，不在自动检查中删除真实业务行。
- 场所码首次验收使用虚构人员资料和测试照片，重点检查二维码访问、照片目录权限、停用或轮换后的旧码失效以及导出审计。
- Windows 客户端升级后检查中文快捷方式、正式图标、当前版本目标和“版本已更新”弹窗；Win7 与 Win10/11 的更新包和清单必须保持平台隔离。
