# 滨湖智慧平台 v0.28.0 更新日志

本次中版本更新汇总 v0.27.16 之后进入主线的功能与修复，重点提升流口任务处理速度、实时协作能力、研判和所内移交流程，并新增可持续维护的帮助中心。

## 更新内容

### 1. 流口任务编辑与分配更顺畅

- 普通任务详情改为稳定的自动保存：文字停止输入后自动提交，下拉、日期和核查结果选择后立即保存，失败时保留草稿并支持重试。
- 未分配任务可在详情中确认后直接领取并保存，避免核查内容已经填写但任务仍未分配。
- 普通保存、领取、地址确认和批量分配只更新实际变化的任务，减少整类业务重建造成的等待。
- 待分配提示、小区筛选和拟登记房屋选择区域保持稳定，快速切换或搜索时旧响应不会覆盖新选择。

### 2. 小区匹配、研判与所内移交闭环

- 唯一、有效且无社区冲突的小区建议可作为自动匹配结果参与分配；多候选、冲突、未匹配和来源异常任务继续阻止分配。
- 六类“无法核实”业务统一进入明确的初步或深度研判阶段，历史遗漏任务可通过受控维护命令接管。
- 基础管控及更高管理岗位可以处理“移交（所内）”，将任务转给目标社区组长；当前待办归接手人，工作量仍归第一核查人。
- 第一核查人责任和移交事件使用独立结构保存，避免后续转派改写原始工作量归属。

### 3. 实时事件与本地任务性能

- 新增基于本地数据库 Outbox 和 Redis Streams 的实时事件通道，浏览器可通过 SSE 接收有权限范围的任务变化通知。
- Redis 暂时不可用时不阻塞业务保存；事件保留在本地 Outbox，恢复后继续投递。
- SSE 初始化连接增加故障降级，实时服务暂不可用时返回明确状态，不再直接造成页面请求失败。
- 修复增量投影查询占位符问题，并统一按单任务更新投影，降低数据库锁竞争和批量操作耗时。

### 4. 仪表盘、在线汇总与自购自住导入

- 修复社区完成情况在零值或兼容字段数据下不显示的问题。
- 在线数据汇总直接展示网格员汇总表和社区汇总表，移除重复表格和移动端二分切换。
- 自购自住名单导入和全民防只读同步只刷新实际变化的模型三任务，减少大批量处理超时。
- 对上传超时、网关超时和文件大小限制提供更明确的提示。

### 5. Markdown 帮助中心

- 侧边栏和移动导航新增“帮助”，所有登录用户均可按分类浏览和搜索平台操作说明。
- 随版本提供 17 篇内置 Markdown 文档，覆盖账号与界面、流口任务、待登记、研判、下发、在线汇总、辖区档案、场所码、数据查询、管理和版本更新等功能。
- 超级管理员可以在线编辑标题、摘要和正文，支持预览、并发版本保护及恢复当前版本内置内容。
- 帮助文档审计不保存 Markdown 正文或人员敏感信息；在线自定义内容不会被后续部署自动覆盖。

## 安全与隐私

本版本继续以本地数据库作为唯一业务主数据源，不恢复腾讯文档读取、写回、删除或 OAuth 运行路径。更新日志和实时事件不包含身份证号、手机号、完整地址、照片、Cookie、密码、令牌或外部平台返回正文。

## 更新说明

桌面客户端优先使用更新服务器提供的增量包；增量包不可用时自动回退到全量包。升级后首次进入已登录业务页面时，将展示本版本更新日志。
