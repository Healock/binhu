# 滨湖智慧平台 v0.28.2 更新日志

本次小版本集中完善地址异常处理、辖区档案与模型三数据核对、流口任务分配性能，并加入场所码云端安全接收和主动拉取的基础能力。

## 更新内容

### 1. 地址异常处理

- 地址匹配出现冲突、多候选或未匹配时，页面不再只禁止操作，而是提供重新匹配、选择候选和人工确认等可执行处理入口。
- 唯一可靠候选继续直接作为自动匹配结果，减少无意义的重复确认。
- 保留人工修正优先级，后续自动匹配不会覆盖已经确认的结果。

### 2. 辖区档案、模型三与全民防核对

- 修复辖区档案筛选区在常用窗口尺寸下过度占用空间的问题。
- 完善“自购自住”人员标签与模型三近期返吴标记的关联处理。
- 修正全民防只读状态核对，避免本地判断与外部只读状态不一致。
- 继续坚持全民防仅查询、不登记、不反馈、不写入的运行边界。

### 3. 流口任务分配性能

- 组长分配核查人时改用轻量任务投影，减少重复读取和整类数据重建。
- 优化分配工作台加载与批量操作反馈，保留逐条资格校验、权限校验和失败原因。
- 提供幂等的投影维护能力，便于部署后核对并补齐历史任务的分配字段。

### 4. 场所码云端基础能力

- 增加带双向证书校验、请求签名和响应验签的场所码云端接收服务。
- 增加长轮询唤醒、主动拉取、幂等确认、失败重试和不确定状态对账能力。
- 场所码管理页可查看本地与云端同步状态，并使用软删除和令牌轮换流程。
- 本版本仅合入安全基础设施；生产环境的真实云端同步和主动拉取开关默认关闭，不会在升级后自动启用。

### 5. 构建与发布稳定性

- 提高网页端、桌面端和 Android 完整前端构建的 Node 内存上限，修复 GitHub Actions 在 Vite 渲染阶段的内存不足失败。
- 修复应用重启时场所码后台任务的独立停止与等待，避免部署重启期间遗留未收尾任务。

## 安全与数据边界

本版本继续以本地数据库作为唯一业务主数据源，不读取、写回或删除腾讯表数据，也不恢复腾讯 OAuth。全民防和居住证平台继续仅用于受控只读查询。场所码云端真实同步与主动拉取保持关闭，待后续独立完成生产密钥、网络和实机验收后再受控启用。
