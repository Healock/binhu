# 滨湖智慧平台 v0.28.5 更新日志

本次补丁重点修复多人同时填写流口指令时，少量保存互相等待并进一步拖慢列表和详情的问题，同时增强影子压力测试的数据一致性核验。

## 更新内容

### 1. 多人保存稳定性

- 本地任务保存统一使用固定数据库锁顺序，减少并发编辑时发生死锁的概率。
- 临时数据库死锁会在服务端安全重试完整事务；锁等待超过短时上限后立即返回，不再让请求等待数分钟。
- 数据版本冲突继续使用 409；系统繁忙和锁等待超时使用独立错误语义，避免把系统故障误报为“他人已修改”。
- 保存失败会完整回滚，不会产生一半业务数据、一半审计记录的情况。

### 2. 保存与派生任务解耦

- 保存请求只同步更新业务主数据和当前页面需要的轻量投影。
- 地址重新匹配、人员标签快照和任务图协调改为提交后由持久化后台队列处理。
- 后台队列按任务版本幂等执行，旧版本任务自动跳过，不会覆盖更新结果。
- 运维中心可查看派生任务排队、运行、成功、跳过、失败和最老等待时间。

### 3. 自动保存体验

- 同一任务的同一字段同一时刻只发送一个保存请求，连续输入会合并为最新草稿。
- 系统繁忙、锁等待超时或数据冲突时继续保留当前草稿，并提供明确的“重试保存”入口。
- 旧请求响应不会覆盖输入期间产生的新草稿，保存成功后只合并当前任务，不刷新整个工作台。

### 4. 日报与压力测试

- 日报刷新使用独立连接上下文，影子环境可关闭自动日报调度，避免压测时与交互保存竞争。
- 压测事件记录保存后的任务版本和操作编号；校验工具按最高已提交版本判断最终值。
- 校验工具区分普通值不一致、未记录写入、派生投影未追平以及失败事务部分写入。

## 安全与数据边界

腾讯表继续保持完全下线，本地数据库仍是唯一业务主数据源。影子压力测试只使用独立数据库、缓存、账号和虚构数据，不复制生产数据，不调用全民防、居住证或场所码外部写入。
