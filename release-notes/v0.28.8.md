# 滨湖智慧平台 v0.28.8 更新日志

## 高并发任务处理

- 后台派生任务会自动合并同一任务的旧版本，并以有界批次集中处理，减少高频编辑时的重复计算和数据库争抢。
- 任务保存与后台计算增加最终版本校验，旧计算结果不会覆盖用户刚刚保存的新内容。
- 普通任务编辑不再读取已经停用的腾讯表单元格元数据，也不再重复写入等价审计，保存链路更轻量。

## 运维与诊断

- 运维中心新增派生任务写入/处理速率、积压等待、批处理耗时、旧版本合并和锁冲突拆批等指标，可直接判断后台是否正在追平。
- 常见的权限、版本冲突和未找到等业务响应改为聚合计数，不再为每一次预期响应创建重量级诊断任务；服务器异常仍保留安全诊断样本。
- 增加显式队列索引维护流程，部署时先测量、备份，再迁移和核验，不在应用启动时隐式改动生产大表。

## 压力测试可靠性

- 75 人突发场景只选择实时可见、仍可编辑的虚构任务，失效任务会立即退出候选池，避免压测脚本反复请求旧任务造成干扰。
- 每个压测阶段使用独立事件记录和一致性核验范围，同时检查接口响应和后台队列是否达到稳态。
