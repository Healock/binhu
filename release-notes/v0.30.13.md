# 滨湖智慧平台 v0.30.13

## 新功能

- 平台后端接管原独立 MAC 兼容服务，管理员和超级管理员可以在“系统设置 → 服务器 MAC”中维护服务器使用的 MAC 地址。
- Windows 客户端会在本机 `127.0.0.1:23333` 提供 MAC 兼容读取服务；离线模式可以维护多个候选 MAC，并将其中一个设为当前使用地址。
- 离线模式支持依次检测已配置社区账号，展示某个候选 MAC 可以登录的社区。检测过程保持居住证系统只读边界，不执行登记、修改、删除或写回。
- Windows 客户端首次运行时自动读取本机硬件网卡 MAC，作为候选地址保存。

## 体验改进

- 桌面客户端登录预发布环境时，只需使用以 `@staging` 结尾的完整账号；登录页不再显示手动切换预发布环境的按钮。
- Staging 发布预检失败时也会生成独立、可追踪的证据目录，成功安装发布网关后不会再被退出清理逻辑误回滚。

## 发布说明

- 生产部署需要在同一维护窗口内停止旧 MAC 兼容容器并释放 `23333` 端口，再由新版后端接管该端口。
- 服务器 MAC 与普通用户在离线模式维护的本机 MAC 相互独立。
- 本版本不包含数据库结构迁移。
