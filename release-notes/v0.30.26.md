# 滨湖客户端 0.30.26

## 首页与界面

- 首页日期范围会按先后顺序整理，避免先选结束日期时出现倒置区间。
- 个性化设置中的待保存选择不会被会话活动刷新重置。
- 右下角任务记录和管理任务队列收纳到一个可展开、收起的快捷菜单。

## 在线汇总

- 指定日期的在岗人数会排除已补录的有效历史请假，修正历史日期的人数及人均统计输入。

## 辖区房屋档案

- 告知书确认以最新完整只读快照为准，历史告知书和旧问题保留但不再累计到当前状态。
- 相同来源内容合并为一个当前代表项；有可信更新时间时采用唯一最新版本，无法判断先后的冲突继续保留核查。
- 未签订且没有签署类型的告知书显示“未签订”，不再仅因实际出租人为空产生问题。
- 新增“从未走访”筛选，按平台已获取的全部历史走访判断，列表、分页和导出使用相同口径。

## 发布与验收

- 本版本同步更新 Windows 7、Windows 10/11 和 Android 客户端。
- 告知书新口径需重新完整读取并确认后生效；旧预览须重新读取。外部读取失败或空结果保留当前快照。
- 自动化测试使用合成数据，不能替代真实 MySQL、上游来源和客户端设备验收。发布前备份覆盖 RegistryData，保留旧程序用于回退。
