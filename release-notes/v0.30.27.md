# 滨湖客户端 0.30.27

## 辖区房屋档案

- “从未走访”和“有走访记录”筛选移入“最近走访日期”表头弹窗，与日期范围一起设置。
- 走访条件生效时表头图标高亮，清空同时复位走访情况和日期。
- 紧凑窗口缩小固定操作列，避免遮挡表头筛选入口，操作按钮仍可换行使用。

## 快捷功能

- 悬浮球及子入口不再显示悬浮提示。
- 支持鼠标按住或手机手指拖动主球；拖动不会打开或收起菜单。
- 子入口跟随主球并向屏幕内展开，窗口缩小时自动调整位置。

## 发布与验收

- 同步更新 Windows 7、Windows 10/11 和 Android 客户端。
- 本版不修改数据库结构、业务权限或外部系统读写行为；本地 MySQL 仍是唯一业务主数据源。
- 自动化验证覆盖桌面及手机尺寸和触摸事件；真实客户端更新与手机真机操作仍需验收。
