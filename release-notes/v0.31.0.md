# 滨湖客户端 0.31.0

## 户号表分组导入

- 一次选择最多十张结构相同的户号表，统一预览并确认导入。
- 每张表可以声明住房类型、是否注销和原查询条数，便于按五类住房与注销状态分组导出后导入。
- 来源状态与声明冲突、重复户号资料不一致、地址变化及较旧批次覆盖较新档案时保留问题，不直接覆盖。
- 预览分别展示来源数量与可导入数量；确认结果区分新增、更新及问题记录。

## 房屋注销筛选

- 房屋档案按已注销、未注销、未知筛选，列表、详情与完整结果导出使用同一来源状态。
- 移除房屋启用与停用操作。历史启用状态不能推断注销状态，缺少来源证据的房屋保持未知。
- 旧版小区标注工作簿需要重新导出；旧导入没有保存注销状态时，按提示重新预览来源文件。

## 小区标注工作簿

- 按当前筛选与排序导出完整房屋记录，并附权限范围内的小区资料、地址、别名与候选。
- 外部 Agent 标注后回导先预览；管理员选择并二次确认后才应用。
- 保留原始地址与社区，拦截过期快照、跨社区、停用小区及越权操作；人工确认替换不默认选中。

## 待登记地址

- 待登记允许直接填写非空现住址，房屋搜索失败或未选择房屋时仍可保存。
- 房屋关联可选，匹配候选不会自动覆盖地址草稿；较旧保存响应不会覆盖新输入。
- 自由地址保存不等于已登记。居住证自动确认仍需要唯一有效房屋与既有只读核验条件。

## 发布与验收

- 同步发布 Windows 7、Windows 10/11 和 Android 客户端。
- 发布前备份八库；程序回退保留新增字段、索引及已导入来源，不自动恢复数据库。
- 自动化测试与模拟浏览器检查已通过；真实 MySQL 大批导入、并发回导和客户端设备更新仍需验收。
