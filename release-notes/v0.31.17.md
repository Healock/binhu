# 0.31.17

## 更新内容

### 1. 辖区档案房屋详情

- 重排房屋详情抽屉，突出当前有效房屋和当前户号。
- 分离历史户号沿革、档案信息、责任告知书、走访和小区关联，改善窄屏与深色模式阅读。

### 2. 照片调取退役守卫

- 通用工单访问、领取、转交、补充、恢复、撤回和决策路径统一拒绝已退役的照片调取工单。
- 增加附件与导入 ZIP 的 SHA-256 对账、暂存清理状态留痕和 measure/verify 门禁。

### 3. 房屋告知书刷新

- 同一现行房屋优先复用原告知书记录，避免来源编号变化产生重复记录。
- 多记录、跨房屋来源和社区冲突进入人工核查，不自动选择或部分写入。

### 4. 逐日出勤与多人日历

- 支持逐日排班、双日上班、双休、工作日调休及多人月历。
- 支持历史请假受控更正与撤销，并统一人员状态、日报、人日和工作日志的出勤取数。

## 技术追溯

- PR #1050：改进辖区档案房屋详情页。
- PR #1051：完善照片调取退役校验与工单守卫。
- PR #1052：同一房屋告知书按原记录刷新，避免来源变化重复新增。
- PR #1053：逐日排班、历史请假更正与多人出勤日历。

## 发布边界

- 本版本不执行照片退役清理或逐日出勤真实数据库迁移；这些操作仍须按维护窗口执行 `measure → backup → migrate --apply → verify`。
- 本版本不恢复腾讯业务读写路径；本地 MySQL 仍是唯一业务主数据源。
