# 0.31.20

## 更新内容

### 场所登记照片恢复

- 增加受控维护流程，从云端已验收提交恢复 Production 中缺失的历史场所照片。
- 恢复前逐条解密并匹配现有照片引用的 MIME、文件大小和 SHA-256；恢复前备份 RegistryData 和现有照片目录。
- 恢复只补齐缺失照片文件，不修改数据库引用、云端状态或 ACK。

## 技术追溯

- 云端 Receiver 新增 mTLS 与签名保护的 accepted 提交恢复接口，并更新 OpenAPI 合同。
- Production 固定维护网关新增 `measure → backup → apply → verify` 照片恢复操作。
- 客户端版本门禁允许发布修订统一短暂不同步的平台，同时拒绝低于任一已发布客户端的版本。
