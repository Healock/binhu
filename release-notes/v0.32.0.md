# 0.32.0

## Kafka/Flink 投影架构

- 建立受控的 Kafka/Flink 投影执行链，多个非权威投影域共享统一事件入口、消费组和派生存储定义。
- 增加 Development/Staging 的投影身份、JobGraph、sink 和查询门禁，保留 Python worker 和 MySQL 权威路径作为兼容回退。
- 架构代码已合入主线，但本版本说明不等同于 Production 或 Staging 的架构验收完成；环境验收、回退演练和完整压测仍按发布清单单独记录。

## 流程中心与业务工作流

- 上线流程配置和运行中心，支持表单定义、版本冻结、节点审批、超时升级、退回重提和管理员挂起处置。
- 增加饮酒报备的 PC 端流程定义与直属领导审批路径，重复加载保持幂等，未启用附件上传的字段不会阻塞提交。

## 数据入口与户号表导入

- 数据上传中心统一展示本地文件和外部来源，增加来源目录、运行历史、调度计划、重试和失败保留能力；自动计划默认关闭。
- 户号表确认导入改为可恢复的后台任务，页面可查看进度，重复确认不会重复写入，旧批次问题保留为可追溯历史。

## 出勤与在线汇总

- 修复日期范围结束于周末时网格员人数被错误归零的问题，人员名册统计与每日排班口径分离。
- 增加“系统建议在岗”只读预览，区分正式排班、请假冲突、系统建议和待确认，不自动修改正式排班。

## 客户端与发布基线

- 同步网页、Windows 和 Android 客户端版本至 0.32.0，并补齐对应的版本一致性检查。
- 本版本包含的主线变更：#1077、#1078、#1079、#1080、#1081、#1082、#1083、#1084、#1086、#1098。

## 验收边界

- 0.32.0 的代码和候选制品必须绑定同一个完整主线提交；Production 与 Staging 的部署、数据库迁移、业务验收、压测和架构开关状态另行记录。
- 权威业务写入、敏感字段、照片正文和外部平台写回继续留在既有 MySQL/Python 边界，除非后续独立验收明确改变该边界。
