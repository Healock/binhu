# 0.32.1

## 指令核查与在线数据汇总

- 指令核查的业务写入统一形成带版本的命令和事件，再由 Kafka、Flink 与 Redis 承接派生处理和查询读模型。
- 在线数据汇总补齐事实 Outbox 与 Kafka 传输合同；本版本只说明已实现的事实链路，不代表在线汇总 Redis 读模型或真实环境验收已经完成。
- 新增业务派生编排合同，集中登记 Development/Staging 的 topic、schema、Flink 运行身份和已实现阶段，减少各业务链路配置漂移。

## 运行稳定性

- 改进 Dev/Staging 事件管道的运行身份传递、Schema Registry、Kafka topic、Flink 作业合同和失败证据，避免错误配置进入运行阶段。
- 完善 Staging 低负载测试的运行隔离、资源观察、Production 状态保护和失败运行清理流程。
- 补强 Dev 服务恢复及 Production 维护流程的固定参数、备份核验和恢复证据。

## 客户端

- 优化场所登记管理页的关键词提示文字。
- 统一网页、Windows 和 Android 客户端版本至 0.32.1。

## 版本范围与验收

- 本版本整理自 0.32.0 发布基线之后合并到主线的改动。PR 编号由发布工作流生成的更新日志保留，用于技术追溯。
- 客户端构建与更新服务器发布不等于 Production 服务端部署或业务验收；服务端环境和架构链路状态仍需按各自流程单独确认。
