# 0.32.3

## 在线数据查询与外部监控

- 移除在线数据查询中没有实际使用场景的移动端卡片列表，保留查询和桌面工作表。
- 在线汇总新增按日、目标、业务类型和社区查看的外部只读监控聚合快照，并提示读取覆盖缺口。
- 外部只读监控在受限 `daily_report` 表保留规范化行版本及成功读取映射，用于重建历史统计；完整行只供监控汇总计算，不进入业务任务、API 响应、日志或审计。
- 补充统一任务与来源记录的目标模型设计文档；该设计不实施数据迁移。

## 发布链路

- Production 发布入口改为只接受已验收的 Staging 不可变制品；本版本代码变更本身不执行 Production 部署。
- 普通发布仍须先完成 Dev 验收，再将同一制品晋级到 Staging 并完成 Staging 验收。

## 验证与限制

- PR CI 全部通过；相关部署合同与外部监控测试通过。
- 外部只读平台和真实 MySQL 未在本次 CI 中联调。逐行监控快照涉及受限个人资料，发布前须确认 `daily_report` 备份和访问控制；Staging 实际部署及业务验收单独记录。
